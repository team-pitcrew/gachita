# 화면 기준: 최종 시안(민준 개선안)

11/15 오너가 화면 기준을 민준님 파일의 '민준 개선안'으로 정했습니다("이 안으로 잡아. 이전 안 말고."). 이 문서는 그 시안의 프레임이 어느 흐름 티켓·코드 파일로 구현됐는지, 시연 35단계가 어디까지 이어지는지, 일부러 목업으로 둔 것과 남은 빈칸을 적습니다. 색·글자·캐릭터 원칙은 [디자인](design.md)이 그대로 기준입니다.

- **시안:** [민준 개선안](https://www.figma.com/design/Y7zFqGUEAFDWTumG30MsOs?node-id=2004-57)(원본, 페이지 `2004:57`), [시연 플로우](https://www.figma.com/design/Y7zFqGUEAFDWTumG30MsOs?node-id=2045-1782)(`2045:1782`). 원본은 보기 권한뿐이라 Figma MCP는 지환의 복제본을 읽습니다(노드 id 같음). 지금 작업본은 11/15 02:55 KST 복제본 `eZ2xsOXkrszqdP489kduCs`이고, 02:30 복제본(`6I2bH121Z5pzWz2yciJUD8`)과 비교해 바뀐 것은 C17 주행 화면뿐입니다(3절).
- **크기:** 차 전체 1682 × 1210, 내비 옆 좁은 창 841 × 1210, 폰 390 × 844. 차는 늘 어두운 화면(#428). 글꼴은 Pretendard(폰은 들어 있음, 차는 앱에 담는 PR 진행 중. Pleos 시스템의 'pretendard' 이름은 다른 글꼴로 이어져 쓰지 않음).
- **코드 기준:** develop `5124012`(11/15 02:38 KST). 프레임 글은 레이어 이름이 아니라 화면에 보이는 실제 글자로 읽습니다(레이어 이름이 옛 글로 남은 노드가 많음).
- 시안 PNG와 프레임 글 전체는 저장소에 넣지 않고 저장소 밖 작업 공간에 둡니다.
