# ADR-0020: 숏폼은 영상 파일 없이 구성 데이터로, 클립은 API가 머리말 인증으로 내준다

* **상태:** 채택됨, 2026-11-14(T43). 같은 번호의 앞선 결정('클립 영상은 `media` 하위 도메인에서 영상 전용 ALB를 거쳐 API가 흘려보낸다', 11/13~14)을 대신한다 — 그 결정은 **영상 파일을 내보낼 때**의 길이었고, 11/14에 숏폼을 영상 파일로 만들지 않기로 했다(지환님).
* **관련:** T43(#63), T76(#158), T75(#156), T64(#118), T63(#117), [ADR-0007](0007-voice-processing-flow.md), [ADR-0013](0013-network-edge-and-isolation.md) 7절, [ADR-0014](0014-transcript-storage.md) 5절

## 배경

기준 문서의 첫 기능은 원래 목소리, 화자별 자막, 가족 캐릭터로 만든 15~45초 숏폼이다(T43). 처음에는 세로 영상 파일을 만들어 내려주려 했고, 그 파일을 어디로 내보낼지가 앞선 ADR-0020이었다. 서명한 S3 주소는 보는 도중 만료·회수 불가·URL 속 자격 문제가 있고, `gachita.mangowhois.ai`는 Cloudflare CDN 약관(Enterprise가 아니면 영상과 큰 파일은 유료 서비스로)에 걸려, `media` 하위 도메인(DNS만) → 영상 전용 ALB → API로 정했다.

11/14에 세 가지가 정해졌다.

- **영상 파일을 만들지 않는다.** 렌더링 서버·외부 영상 업체(Higgsfield 등, 기본 약관상 학습 사용·국외 이전·18세 이상) 없이, 차와 웹이 원음 클립 위에 자막과 캐릭터를 그 자리에서 그린다.
- **장면 후보는 규칙으로 고른다.** Claude API 계약 전이라 LLM을 쓰지 않는다.
- **클립은 S3 클립 전용 버킷**(T76, 버전 관리 끔, 2일 수명 규칙)에 두고, 차량 앱이 API로 올린다(머리말 인증).

## 검토한 선택

| 선택 | 좋은 점 | 걸리는 점 |
|---|---|---|
| 서버가 세로 영상을 렌더링(ffmpeg) | 파일 하나로 공유·저장이 쉬움 | 이미지에 ffmpeg, 주차 중 렌더링 대기, 영상 내보내기 길(앞선 ADR-0020: 두 번째 ALB 월 약 $30, 인증서, 쿠키) |
| 외부 영상 업체(캐릭터 입모양) | 보기 좋음 | 아이 목소리의 국외 이전·학습 사용, 18세 이상 약관(#117 조사). 원음을 차 밖 제3자에게 보냄 |
| **구성 데이터 + 그 자리 재생** | 렌더링·업체·영상 길 없음. 클립(150~250 KB 오디오)만 기존 API로 | 파일로 내려받거나 SNS에 올릴 수 없음. 입모양 없음 |

## 결정

### 1. 장면 후보 — 규칙 (`GET /api/trips/{code}/scene-suggestions`)

- 각 발화에서 시작하는 30초 창의 **발화 수**와 **말한 사람 수**(화자 대조로 붙은 프로필, 없으면 좌석 구역)로 점수 = 발화 수 + 2 × (말한 사람 수 − 1). 발화 4개 미만은 후보가 아니다.
- 사람이 이미 남긴 장면(moments)의 구간과 겹치는 창은 뺀다(같은 장면을 두 번 고르지 않게). 점수 순으로 서로 겹치지 않게 최대 5개를 골라 시각 순으로 준다(여행 앞뒤에 퍼지게).
- 구간은 첫 발화 1초 전 ~ 마지막 발화 4초 뒤, 최대 45초. 사람이 고르면 `POST /moments`에 `at`·`from`·`to`를 남기고, 차가 그 구간을 잘라 클립으로 올린다(T63 → T76).
- 코드는 `backend/api/scenes.js` 한 파일(DB·네트워크를 모르는 순수 함수). 요청할 때만 계산하고 저장하지 않는다.

### 2. 숏폼 — 구성 데이터 (`GET /api/trips/{code}/shortform`)

- 클립이 올라온 장면마다 `{ clip(소리 주소), startAt, seconds, cues[{ start, end, text, participantId, seatArea }] }`와 출연(`cast`: 이름, 캐릭터, 자리).
- 자막 큐는 클립 구간 안의 발화. 발화의 `at`을 말 시작으로 보고, 끝은 글자 수로 어림한다(글자당 0.15초, 1~6초). 재전사(T75)가 고친 자막이 있으면 그것을 쓴다.
- 말한 사람은 화자 대조(T38)로 붙은 프로필의 참가자만. 자리만으로 이름을 붙이지 않는다.
- 웹은 9:16 재생 페이지(web 세션), 차는 그 자리 재생(car-ui 세션)으로 같은 데이터를 그린다.

### 3. 내려주는 길 — 기존 API 주소, 머리말 인증

- 클립은 `gachita.mangowhois.ai/api/trips/{code}/recordings/{id}`에서 API가 S3에서 읽어 준다. 인증은 참가자 토큰 머리말(`Authorization`)이고, URL에 토큰이나 서명을 싣지 않는다(Pleos 앱 보안 가이드). 웹의 `<audio>`는 머리말을 붙일 수 없으니 `fetch` → blob → `<audio>`로 튼다. 클립이 작아(150~250 KB) 범위 요청·스트리밍이 필요 없다.
- **차로 돌려주는 길:** 차는 이미 쥔 참가자 토큰으로 `GET /shortform`과 클립을 받아 주차 화면에서 그 자리에서 재생한다. 따로 만들어 보낼 완성본이 없다.
- 영상 파일이 없으므로 Cloudflare CDN 약관의 '영상과 큰 파일'에 해당하지 않는다고 본다(작은 오디오와 JSON). 그래서 앞선 결정의 `media` 하위 도메인, 영상 전용 ALB, 그 인증서·레코드, 쿠키 인증, 이 길만의 요청 수 제한은 **만들지 않는다.**

## 결과

- 비용: 후보·구성 계산은 서버 CPU만($0, LLM·렌더링 없음). 저장은 여행당 클립 약 2 MB(장면 10개 × 150~250 KB), 2일 수명. 내려받기는 가족 몇 명 × 약 2 MB. 앞선 결정의 두 번째 ALB(펴 있는 동안 월 약 $30)가 없어진다.
- 인프라(T64)는 클립 전용 버킷, API 서비스 계정 역할, S3·STS egress, 환경 변수만 만든다(#158 계약). ADR-0013 7절의 '클립·사진' 줄과 ADR-0014 5절은 이 문서를 가리킨다.
- 잃는 것: 숏폼을 파일로 내려받거나 SNS에 올리는 기능, 캐릭터 입모양. 밀도 규칙은 이야기의 '재미'를 직접 보지 않는다(LLM 계약이 생기면 이 창들을 후보로 넘겨 이유를 쓰게 한다). 파일 공유가 필요해지면 렌더링과 앞선 결정의 길을 다시 본다.
- 확인하지 못한 것: 실제 가족 대화에서 후보의 질, 사람 목소리에서 글자 수 어림 자막의 맞음, 웹·차 재생 화면(아직 없음). 서버 시험의 합성 대화로만 봤다.
