# ADR-0019: 화자는 좌석 구역으로 줄이고 등록한 목소리와 대조해 프로필에 붙인다

* **상태:** 채택됨(1차 임베더), 2026-11-13 — 학습된 모델 도입은 정확도 표(지환 시험 음성) 뒤에 다시 연다
* **관련:** T38, #61, ADR-0007(음성 처리), ADR-0008(차량 수음·좌석), T37(좌석 판정), T39(발화 표), ADR-0014

## 배경

기준 문서는 짧은 목소리 등록으로 화자를 맞추고 화자별 자막을 만든다. Pleos SDK에는 화자를 알려 주는 공개 API가 없다(STT SDK 안의 `AmbientAiApi`는 특권 앱 전용, 11/13 확인). 11/13 E2E 실측에서 좌석 두 구역은 차량 앱이 스테레오 채널로 가렸지만(8/8), 같은 구역 안의 사람은 매크로폰·MFCC 간이 대조기로 7/8이었다. ADR-0008의 결정: 좌석 구역은 차량 앱이, **같은 구역 안의 구분은 서버가 등록한 목소리와 대조한다.**

## 검토한 선택: 임베딩 모델 후보

수치는 공개 자료 기준 어림이다. 실제 값은 지환이 넘겨줄 시험 음성(한국어 합성 가족 4역)으로 잰 정확도 표로 대체한다.

| 후보 | 정확도(공개 벤치 어림) | 한국어·아이 목소리 | 실행 비용 | 이야기 |
|---|---|---|---|---|
| **SpeechBrain ECAPA-TDNN(ONNX)** | VoxCeleb1 오류율 ~1% 안팎 — 후보 가운데 가장 좋음 | 화자 검증은 언어와 무관해 한국어에도 널리 씀. 학습 데이터가 성인 위주라 아이 목소리는 실측 필요 | 파라미터 약 5M, 모델 수십 MB, CPU에서 실시간의 수십 배 빠름 | 1순위 |
| Resemblyzer(d-vector) | ECAPA보다 오류율 2~3배 높음(구형 구조) | 같음 | 매우 가벼움 | 빠른 시험이 필요할 때 |
| 3D-Speaker/WeSpeaker(ResNet·ECAPA) | ECAPA와 비슷한 급, ONNX 제공 잘 됨 | 다국어 | 비슷 | 대안 |
| 클라우드 화자 인식 API | — | — | 호출당 비용 + **원음이 제3자에게 전송** | 기각(원음 최소 전송 원칙) |

서버는 표준 라이브러리와 pg만 쓰는 원칙(architecture.md) 때문에 모델을 서버 프로세스 안에서 돌리지 않는다.

## 결정

- **후보는 두 단계로 줄인다.** 좌석 구역(차량 앱, T37)이 먼저 후보를 그 자리의 사람들로 좁히고, 서버가 그 후보의 등록 목소리와 발화 음성을 대조해 확신도를 매긴다. 가장 높은 확신이 기준(`VOICE_MATCH_THRESHOLD`, 초안 0.9)을 넘으면 그 프로필, 아니면 **'모름'**으로 둔다.
- **등록 음성 원본은 어디에도 저장하지 않는다.** 프로필마다 등록 음성을 받아 대조용 벡터만 `voice_prints` 표에 남긴다(생체 정보 최소 보관). 발화 음성도 대조에만 쓰고 즉시 버린다 — 이는 보관 범위를 정한 ADR-0007('고른 장면만')과 구분되는 **일시 전송**이다.
- **1차 임베더는 참조 구현으로 API 계약을 고정한다.** `providers/voice.js` — 순수 JS로 WAV(16 kHz PCM)를 읽어 로그멜 평균·분산과 음높이 히스토그램(60~500 Hz 로그 눈금 20구간)을 그룹별로 평균을 빼고 이어 붙인 벡터(의존성 0). 합성 음성 시험에서 같은 목소리 0.9998, 다른 기본음(180~340 Hz) 0.46~0.60 — 아이와 어른처럼 음높이가 크게 다른 경우를 가린다. 같은 성인끼리 가까운 목소리는 이 임베더의 한계다.
- **학습된 모델(ECAPA-TDNN ONNX) 도입은 별도 프로세스로 한다.** 서버가 임베더 주소를 환경 변수로 받아 호출하는 자리를 `providers/voice.js`에 둔다. 도입 여부와 임계값은 발화 길이별(등록 문장 수별) 정확도 표로 정한다 — 티켓 완료 기준.
- **대조가 끝나면 발화 줄의 `profile_id`를 채운다**(ADR-0014). 기록본·피드에 화자가 붙는다.
- **동의 문구(등록 화면에 더하는 글):**
  > 목소리는 화자를 가리는 값으로만 바꿔 저장하고 원본은 버립니다. 등록한 목소리로 여행 녹음에서 내 말을 찾아 내 기록에 묶습니다. 지우면 바로 사라집니다.

  아이 목소리는 보호자 동의 전제다(그룹 구조, ADR-0009). 아이는 토큰이 없으므로 **그 아이 프로필을 만든 대표가 대신 등록하고 지운다**(`POST·DELETE /api/groups/:id/members/:profileId/voice`). 이 문구는 voice.md의 동의 문구 단락과 한 덩어리로 맞춘다(#55 병합 뒤 반영).
- **지우는 길:** `DELETE /api/profiles/me/voice`로 대조용 값을 즉시 지운다. 프로필을 지우면 함께 지운다. 대표가 아이를 내보내거나 그룹·자기 프로필을 지워 아이 프로필이 지워질 때도 함께 지운다.
- **대조는 여행 줄을 잠그지 않는다.** 대조는 여행 문서를 바꾸지 않는다. 잠근 채 음성(최대 5 MB)을 받으면 업로드가 느릴 때 같은 여행의 동의 철회가 질의 2초 제한(T26)에 걸려 실패한다.
- **좌석 구역을 모르면** 그 여행의 프로필 참가자 모두를 후보로 대조한다(T37 판정이 '모름'일 때).

## 결과

- `POST /api/profiles/me/voice`(등록, 이진 WAV), `POST·DELETE /api/groups/:id/members/:profileId/voice`(대표가 아이 대신), `POST /api/trips/:code/voice-match`(대조) — openapi 0.6.0.
- 번호: 처음 0016으로 썼으나 develop의 0016(SLO·Postgres 하나)·0017·0018과 겹쳐 0019로 옮겼다.
- `profiles-5-voice.sql`(`voice_prints`), `providers/voice.js`(참조 임베더).
- 남은 것: 지환 시험 음성으로 정확도 표(발화 길이별) → ECAPA 도입·임계값 확정, 등록 길이에 따른 비교. 참조 임베더는 시연용 한계임을 문서에 그대로 둔다.
