# ADR-0021: 숏폼은 영상 파일 없이 구성 데이터로, 클립은 기존 API 주소에서 내준다

* **상태:** **일부 대체됨(2026-11-14)** → [ADR-0022](0022-shortform-video-on-device-and-server-generation-off.md). '영상 파일을 만들지 않는다'와 '외부 영상 업체를 쓰지 않는다'는 ADR-0022가 대신한다(기기에서 영상 파일을 만들고, 서버의 힉스필드 생성은 꺼서 배포). 장면 후보 규칙(1절), 숏폼 구성(2절), 클립을 기존 API 주소에서 머리말 인증으로 내주고 `media` 하위 도메인을 두지 않는 것(3절), 저장(4절)은 그대로 유효하다. 아래 배경의 '영상 파일을 만들지 않는다'는 그때의 판단 기록으로 남긴다.
* **이전 상태:** 채택됨, 2026-11-14 — 영상 파일을 만들지 않음, 장면 후보는 규칙으로(지환님, 11/14), media 하위 도메인을 두지 않음(부모 결정 B, 11/14 03:10)
* **대체:** [ADR-0020](0020-media-delivery-subdomain.md)(클립·영상을 `media` 하위 도메인에서 내줌)
* **관련:** T43(#63), T76(#158), T75(#156), T64(#118, #167), T63(#117), [ADR-0007](0007-voice-processing-flow.md), [ADR-0013](0013-network-edge-and-isolation.md) 7절, [ADR-0014](0014-transcript-storage.md) 5절

> **11/14 T90으로 대체됨(보관 기간).** 이 문서의 '48시간' 보관·만료 문장은 옛 결정입니다. 지금은 여행·발화·원음 클립·영상·공유를 시간이 지났다는 이유로 지우지 않고, 사람의 요청(삭제, 동의 철회)으로만 지웁니다 — `backend/api/retention.md`. 나머지 결정은 그대로입니다.

## 배경

기준 문서의 첫 기능은 원래 목소리, 화자별 자막, 가족 캐릭터로 만든 15~45초 숏폼이다(T43). 처음에는 세로 영상 파일을 만들어 내려주려 했고, ADR-0020은 그 파일을 Cloudflare를 지나지 않는 `media` 하위 도메인과 영상 전용 ALB로 내보내기로 했다(영상의 범위 요청, `<video>`의 쿠키 인증, Cloudflare의 영상·큰 파일 약관 때문).

11/14에 정한 것:

- **영상 파일을 만들지 않는다.** 렌더링 서버도 외부 영상 업체도 쓰지 않는다. Higgsfield 등은 기본 약관상 학습에 쓰고, 국외로 옮기며, 18세 이상만 쓸 수 있다(#117 조사). 차와 웹이 원음 클립 위에 자막과 캐릭터를 그 자리에서 그린다.
- **장면 후보는 규칙으로 고른다.** Claude API 계약 전이라 LLM을 쓰지 않는다.
- **클립은 S3 클립 전용 버킷**에 둔다. 버킷은 T64가 만들고 버전 관리를 끈다. 차량 앱이 API로 올린다(T76, 머리말 인증).

그러면 나가는 것은 장면 클립(16 kHz 모노 WAV, 0.5~1.1 MB)과 JSON뿐이라 ADR-0020의 전제가 사라진다.

## 검토한 선택

| 선택 | 좋은 점 | 걸리는 점 |
|---|---|---|
| 서버가 세로 영상을 렌더링(ffmpeg) | 파일 하나로 공유·저장이 쉬움 | 이미지에 ffmpeg, 주차 중 렌더링 대기, 영상 내보내는 길(ADR-0020: 두 번째 ALB 월 약 $30, 인증서, 쿠키) |
| 외부 영상 업체(캐릭터 입모양) | 보기 좋음 | 아이 목소리의 국외 이전·학습 사용, 18세 이상 약관. 원음을 차 밖 제3자에게 보냄 |
| **구성 데이터 + 그 자리 재생, 클립은 기존 API 주소** | 렌더링·업체·별도 길 없음 | 파일로 내려받거나 SNS에 올릴 수 없음. 입모양 없음 |

## 결정

### 1. 장면 후보 — 규칙 (`GET /api/trips/{code}/scene-suggestions`)

- 각 발화에서 시작하는 30초 창을 보고 점수 = 발화 수 + 2 × (말한 사람 수 − 1)을 매긴다.
  - 말한 사람은 좌석 구역으로 센다. 구역을 모르면 화자 대조로 붙은 프로필로 세고, 둘 다 없으면 세지 않는다.
  - 발화 4개 미만인 창은 뺀다.
- 사람이 이미 남긴 장면의 구간과 겹치는 창은 뺀다. 구간이 없는 장면은 `at` 앞 20초~뒤 10초로 본다.
- 점수 순으로 서로 겹치지 않게 최대 5개를 고르고, 시각 순으로 돌려준다.
- 구간은 첫 발화 1초 전부터 마지막 발화 4초 뒤까지이고 15~35초다. 후보의 발화는 30줄까지 보여 준다.
- 장면으로 남길 수 있는 시각의 발화만 본다.
- 사람이 고르면 `POST /moments`에 `at`·`from`·`to`(1~60초)를 남긴다. 차가 그 구간을 잘라 올린다(T63 → T76).
- 규칙은 `backend/api/scenes.js` 한 파일에 있는 순수 함수다. 창을 복사하지 않고 두 손가락으로 훑으므로, 발화 2만 줄이 한 순간에 몰려도 1초 안에 끝난다.

### 2. 숏폼 구성 (`GET /api/trips/{code}/shortform`)

- 클립이 올라온 장면마다 다음을 돌려준다.
  - 소리 주소 `clip`(`/api/trips/{code}/recordings/{id}`, 같은 출처)
  - 클립 첫 표본의 시각
  - 자막 큐: 클립 안의 초, 글, 화자 대조로 붙은 참가자, 좌석 구역
- 출연(이름, 캐릭터, 자리)도 함께 준다.
- 자막의 끝은 글자 수로 어림한다(글자당 0.15초, 1~6초). 발화에 끝 시각이 없기 때문이다. 다음 자막에서 자르되 최소 1초는 남긴다. 같이 말하면 자막이 겹친다.
- 재전사(T75)가 고친 글이 있으면 그 글을 쓰고, Pleos 원문도 함께 준다.
- 권한은 기록본과 같다. 녹음에 동의한 참가자만 볼 수 있다.

### 3. 내려주는 길 — 기존 주소, 머리말 인증

- 클립은 `gachita.mangowhois.ai/api/trips/{code}/recordings/{id}`에서 받는다. API가 권한을 확인하고 S3에서 읽어 준다(T76).
- 인증은 참가자 토큰을 `Authorization` 머리말에 실어 보낸다. 토큰도 S3 서명도 URL에 싣지 않는다(Pleos 앱 보안 가이드). 응답은 `Cache-Control: private, no-store`다.
- 웹은 `fetch` → blob → `<audio>`로 튼다. 차는 같은 주소에 머리말을 붙여 받는다.
- 차로 따로 만들어 보낼 완성본은 없다. 차가 같은 데이터를 주차 화면에서 그 자리 재생한다.
- 나가는 것은 작은 오디오와 JSON이다. 그래서 Cloudflare CDN 약관의 '영상과 큰 파일'에는 해당하지 않는다고 본다(약관 해석, 문의는 하지 않음).
- `media` 하위 도메인, 영상 전용 ALB와 그 인증서·레코드, 쿠키 인증, 그 길만의 요청 수 제한은 만들지 않는다. 기존 주소의 Cloudflare WAF·요청 수 제한을 그대로 쓴다.

### 4. 저장

- 클립 전용 S3 버킷(`CLIPS_BUCKET`)을 쓴다: 서울, 버전 관리 끔, SSE-S3, 공개 차단.
- 버킷과 API 서비스 계정 역할(그 버킷의 Put·Get·DeleteObject와 ListBucket)은 T64가 만든다.
- 지우기는 API가 직접 한다.
  - 사람이 지우면 바로 지운다.
  - 동의 철회와 48시간 만료는 같은 트랜잭션에서 지울 키를 적어 두고, 커밋 뒤 버킷에서 지운다. 실패하면 10분마다 다시 한다.
  - 사람이 지운 표시는 여행이 닫힐 때까지 남는다.
- 버킷 수명 규칙은 뒷받침일 뿐이다. 올린 뒤 2일을 다음 UTC 자정으로 올려 만료하고 S3의 지우기가 비동기라, API가 놓친 객체는 최대 약 3일 남을 수 있다.

## 결과

- **비용:**
  - 후보·구성 계산은 서버 CPU만 쓴다($0, LLM·렌더링 없음).
  - 클립은 초당 32 KB다. 장면 하나는 0.5~1.1 MB, 장면 10개는 약 5~11 MB이고 수명은 최대 약 3일이다.
  - ADR-0020의 두 번째 ALB(펴 있는 동안 월 약 $30)가 없어진다.
- **인프라(T64):** 클립 전용 버킷, API 역할, 그 버킷·STS로 나가는 길, `CLIPS_BUCKET`만 만든다.
- **잃는 것:**
  - 숏폼을 파일로 내려받거나 SNS에 올릴 수 없고, 캐릭터 입모양도 없다.
  - 밀도 규칙은 이야기의 '재미'를 직접 보지 않는다. LLM 계약이 생기면 이 창들을 후보로 넘겨 이유를 쓰게 한다.
  - 파일 공유가 필요해지면 렌더링과 ADR-0020의 길을 다시 본다.
- **확인하지 못한 것:**
  - 실제 가족 대화에서 후보의 질
  - 사람 목소리에서 어림한 자막 끝
  - 웹·차 재생 화면(web·car-ui 세션이 만듦)

  서버 시험의 합성 대화로만 확인했다.
