# ADR-0009: 가족과 동승자는 우리 그룹으로 묶고 QR로 초대한다

* **상태:** 제안, 2026-11-13 (T44. PR 병합으로 정함)
* **관련:** T44, #68, T45, T46, T21(ADR-0006), T22(ADR-0004), T39

## 배경

기준 문서(참가신청서 문구정리본, 11/13)의 첫 고객은 어린 자녀와 이동하는 부모입니다. 출발 전에 가족 프로필을 등록하고, 다음 탑승부터 이어 쓰며, 활성 사용자는 가족 대표 계정으로 셉니다. 지금 서버는 계정 하나에 프로필 하나이고(ADR-0006), 여행 코드로 그 여행에만 참가합니다. 계정이 없는 아이를 둘 자리와 가족을 묶는 자리가 없습니다.

현대차 쪽 계정으로 가족 프로필을 받아 올 수 있는지 공개 문서를 다시 봤습니다(2026-11-13).

| 길 | 문서에 적힌 것 | 가족 프로필에 쓸 수 있나 |
|---|---|---|
| Pleos Playground Vehicle Data API(사업자용) | OAuth 2.0. `api.pleos.ai/v1/auth/login`에 `brand`(hyundai·kia·genesis)를 주면 차량 제조사의 로그인 창이 뜨고, 인증코드를 토큰(1시간, 갱신 토큰 90일)으로 바꿈. 이어서 차량 선택과 데이터 공유 동의. Playground 프로젝트를 만들고 사용 신청과 심사를 거쳐야 함 | 차량 소유자의 차량 데이터를 받는 길. 사용자 정보나 가족을 돌려주는 API는 문서에 없음 |
| Hyundai Developers 계정 API | OAuth 2.0 인증코드와 사용자 정보 조회. 블루링크 고객 대상이고 공유받은 차량은 빠짐. 프로젝트 등록과 상용화 심사(ADR-0004의 조사) | 대표 한 사람의 계정 확인까지. 가족 구성원은 받지 못함 |
| 차량 안의 Pleos 프로필 | 차량마다 오너를 포함해 프로필 슬롯이 최대 6개이고 이메일로 사용자를 초대함(Connect Mobile Console 안내). 콘솔은 사내 계정으로 들어감 | 앱이 이 프로필을 읽는 공개 SDK나 API는 문서에 없음. Connect SDK(Vehicle, NaviHelper, FusedLocation, STT, TTS, Gleo)에도 계정 기능이 없음. STT·TTS의 서버 모드가 쓰는 인증(`registerApp`, Client ID와 Secret)은 앱을 인증하는 것이고 사용자 계정이 아님 |

Pleos 보안 가이드는 차량 앱의 소셜 로그인을 전제로 토큰을 안전한 저장소에 두고, 운전자가 바뀔 때 쉽게 계정을 바꿀 수 있어야 한다고 적습니다. 실제로 로그인해 보거나 사용 신청을 해 본 것은 아닙니다. 모두 문서에서 읽은 것입니다.

## 검토한 선택

| 선택 | 좋은 점 | 걸리는 점 |
|---|---|---|
| 현대 계정으로 가족을 받아 옴 | 차량과 계정이 이미 이어져 있음 | 가족이나 프로필을 주는 API가 문서에 없음. 사용 신청과 심사가 필요하고 소유자만 대상 |
| 구성원마다 OAuth 계정 | 지금 구조 그대로 | 아이는 계정이 없음. 차에 탈 때마다 로그인할 수 없음 |
| **우리 그룹 + QR 초대** | 계정 없는 구성원을 둘 수 있음. 폰 카메라만 있으면 들어옴. 여행 코드 참가와 같은 방식이라 고칠 것이 적음 | 초대 주소가 새면 모르는 사람이 들어옴. 그룹과 기기별 토큰을 새로 만들어야 함 |

## 결정

**가족과 동승자는 우리 서버의 그룹으로 묶고, 차량 화면이나 대표의 폰에 뜨는 QR로 초대합니다.**

- 그룹은 가족과 동승자 두 종류입니다. 대표 한 사람이 만들고, 계정이 없는 구성원(아이)은 대표가 만든 프로필로 둡니다.
- QR에는 만료 시각과 횟수 제한이 있는 초대 주소(`https://gachita.mangowhois.ai/j/<초대>`)를 담습니다. 찍은 사람은 폰 브라우저에서 설치 없이 수락하고, 기록 동의는 각자 따로 받습니다(기본값 꺼짐).
- 찍은 사람에게 계정이 있으면 로그인해 있던 프로필로 들어옵니다. 가입한 적이 없거나 계정이 없으면 같은 브라우저에서 프로필 등록 화면을 띄워 이름이나 닉네임, 캐릭터나 사진을 넣고 들어옵니다.
- 대표의 계정은 지금처럼 구글로 잇습니다(ADR-0006). 한 프로필을 차량과 폰에서 함께 쓰도록 기기마다 토큰을 둡니다.
- 현대 계정은 제휴 조건이 확인되면 대표의 차량 소유를 확인하는 데 씁니다(ADR-0004의 제공자 자리). 가족 구성원을 받아 오는 용도로는 쓰지 않습니다.

## 결과

- 서버에 그룹과 초대, 프로필 사진 올리기가 생깁니다(T45). 차량 앱과 웹앱에 QR 초대, 수락, 프로필 등록 화면이 생깁니다(T46, 에뮬레이터 확인은 지환). 주소는 [ADR-0010](0010-domain-and-cloudflare-edge.md)을 따릅니다.
- 화면 문서에 초대와 수락 흐름을 더합니다(T42).
- 기록본(T39)은 구성원 프로필에 묶이므로, 그룹을 나가거나 지울 때의 처리를 T45에서 함께 정합니다.
- 확인하지 못한 것: Vehicle Data API가 한국에서 신청되는지와 심사 기간(문서의 문의처는 유럽 법인), 차량 화면에서 구글 로그인 창을 띄울 수 있는지, 실차 화면의 QR을 폰으로 읽을 수 있는 거리와 밝기.
