# 음성 처리 API 초안

2026-11-13, [ADR-0007](../adr/0007-voice-processing-flow.md)의 설계를 API 모양으로 옮긴 **초안**입니다. 구현 전이라 `openapi.yaml`에는 아직 없습니다. 만들 때 이 문서를 openapi.yaml로 옮기고 서버·테스트와 같은 PR에서 고칩니다(개발 규칙). 오류 형식과 크기 제한(10 KB)은 기존 API와 같지만, 조각 오디오 본문은 그보다 크므로 **올리기 경로만 따로 한도를 둡니다**(아래).

## 폰 → 서버: 원음 조각

대표 폰이 녹음한 원음을 1분 조각으로 잘라 올립니다. 통신이 끊기면 로컬에 쌓았다가 재연결 뒤 시각 순서대로 다시 올립니다.

| 요청 | 본문 | 하는 일 |
|---|---|---|
| `POST /api/trips/:code/recordings` | multipart: `chunk`(오디오, 최대 5 MB), `startedAt`(epoch ms), `durationMs` | 조각을 받아 저장. 같은 `startedAt`이면 덮어쓰지 않고 200. 참가자 토큰 필요 |
| `GET /api/trips/:code/recordings` | | 서버가 받은 조각 목록(`startedAt`·길이·상태). 폰이 무엇이 밀렸는지 안다 |
| `DELETE /api/trips/:code/recordings` | | 원음 전체를 즉시 지움(동의 철회). 받아쓰기가 끝났으면 텍스트는 남김 |

조각 상태: `stored`(받음) → `transcribed`(받아쓰기 끝) → `dropped`(48시간 지나 지움 또는 참가자가 지움).

## 서버 → 받아쓰기 결과

| 요청 | 하는 일 |
|---|---|
| `GET /api/trips/:code/transcript?v=버전` | 받아쓰기 결과. 한 줄: `{ speaker, text, at, durationMs }[]`. 아직 준비 중이면 `{ status: "pending", doneUntil }` |

- 화자 라벨은 STT 제공자가 매기는 `1, 2, 3…`을 그대로 둔다(누구인지 매핑은 화면 문서 과제).
- 여행 버전(`v`) 규칙은 기존 여행 읽기와 같아서, 받아쓰기가 끝날 때 여행 `version`이 오른다.

## 장면 후보(추천)

LLM이 후보만 추천하고 사람이 고릅니다(ADR-0007). 확정된 장면은 이미 있는 `POST /api/trips/:code/moments`로 남긴다 — 새 경로를 만들지 않는다.

| 요청 | 본문 | 하는 일 |
|---|---|---|
| `POST /api/trips/:code/scene-suggestions` | `{ windowMs? }` | 받아쓰기와 moments를 보고 후보를 만든다: `{ at, why }[]`. 만들어 둔 뒤 결과로 돌려줌(비용 때문에 요청할 때만) |

## 동의 문구(기록 동의에 더하는 글)

> 대화가 녹음되어 받아쓰기 위해 클라우드(제3자)로 전송되고, 원음은 여행을 마친 뒤 48시간 뒤 지워집니다. 남는 것은 받아쓴 텍스트와 장면입니다. 원음은 참가자가 요청하면 바로 지울 수 있습니다.

## 남은 것

- 폰 녹음 확인(화면 뒤·화면 꺼짐·길이) — T10 남은 범위. 끝나야 올리기를 만든다.
- STT·LLM 서비스 계약과 요금 재확인(external.md).
- 화자 라벨을 사람(참가자)과 잇는 방법 — 화면 문서(T18)와 함께.
