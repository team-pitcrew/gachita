# 외부 API

2026-11-13 기준입니다. **API 서버가 지금 부르는 외부 API는 구글 OAuth(T21, ADR-0006)와 클립 버킷(AWS S3, T76)입니다.** 아래는 그것과 기준 문서(참가신청서 문구정리본, 11/13)를 구현하려면 필요한 것의 결정 상태입니다. 차량 앱이 기기 안에서 부르는 Pleos SDK는 외부 통신이 아니지만 같이 적었습니다.

## 차량 앱이 기기 안에서 부르는 것

| 이름 | 쓰는 곳 | 우리가 확인한 것 | 걸리는 점 |
|---|---|---|---|
| Pleos NaviHelper 3.0.5 | 경유지 반영(`addWaypoint`), 현재 위치, 장소까지 거리·시간(`requestTrip`) | 에뮬레이터(11/12): 조회와 `requestTrip`은 화면 전환 없이 0.2초 안에 답. 경유지 추가는 내비가 앞으로 나오고 약 6초 뒤 `onWaypointChanged` | 경유지는 최대 2곳. `cancelRoute`는 이번에 안내를 끝내지 못함. 실차 미확인 |
| Pleos Vehicle SDK 2.3.2 | 기어 읽기, 좌석별 온도·열선·통풍 | 에뮬레이터: 운전석 온도 설정과 복원(11/10), 시트 열선·통풍 반영(11/1) | 차종마다 지원이 다름. 권한은 Pleos App Market과 사전 협의가 필요하다고 심사 가이드에 적힘 |
| Pleos TextToSpeech 3.3.1 | 제안과 알림을 말로 | 에뮬레이터에서 소리 확인 | 음악·내비 안내와 겹칠 때 미확인 |
| 차량 마이크 | 대화 수음(마이크 포그라운드 서비스, `AudioRecord` 16 kHz 2채널) | **됨(에뮬레이터, T10·E2E 11/13)**: 11분 연속 수음, 스테레오 두 채널이 완전히 분리돼 좌석 두 구역 판정 8/8 | Gleo와 마이크를 나눠 씀(호출어 감지→수음 정지→운전대 버튼→포커스 복귀로 재개, T41). 실차 미확인 |
| Pleos STT(ON_DEVICE) 3.x | 대화 받아쓰기. 앱이 받은 원음을 `sendAudio()`로 넣음 | **됨(에뮬레이터, 11/13)**: 11분 150문장, 말이 끝난 뒤 0.6초 | 사람 목소리·차 안 소음 정확도는 재지 않음(T36 실측 뒤 재검). 화자·좌석을 주는 공개 API 없음(좌석은 채널로 차량 앱이 판정, 화자는 서버가 대조 — T37, T38). `request()`로 STT가 직접 마이크를 열면 우리 수음(`AudioRecord`)과 같이 쓸 때 무음만 받음(T10) |

## API 서버가 부르게 될 것

| 쓰임 | 후보 | 왜 필요한가 | 결정 |
|---|---|---|---|
| 계정 로그인(OAuth) | Google OAuth 2.0 | 기기를 바꿔도 프로필을 이어 받음(T21) | **씀(ADR-0006).** 사용자 번호와 이름만 받음. 클라이언트 값은 환경 변수로만 |
| 우회 시간 계산 | 카카오모빌리티 길찾기(경유지 5곳), 네이버 클라우드 Directions 5·15 | `requestTrip`은 지금 위치에서 장소 한 곳까지만 답해 '들르면 몇 분 늘어나는지'를 주지 못함 | 정하지 않음. 요금과 약관을 보고 고름 |
| 지도 표시 | 카카오 지도, 네이버 지도 | 주행 기억 지도(웹앱, 주차 뒤 차량 화면) | 정하지 않음 |
| 받아쓰기와 화자 구분 | AWS Transcribe(화자 구분 포함), Google Speech-to-Text, 네이버 클로바 | 대화에서 부탁과 장면을 찾음 | **받아쓰기는 차량의 Pleos STT로 함(ADR-0008·ADR-0007) — 서버가 부르지 않음.** 서버 ASR은 대안: Pleos STT 정확도가 모자라면 다시 엶(그땐 원음 전체가 제3자에게 전송되고 30분 여행 ≈ $0.5~1). 화자 구분은 좌석 채널(차량)+목소리 대조(서버, T38)로 우리가 함 |
| 장면 고르기 | Claude API | 기록본에서 이야기의 시작과 끝 후보를 추천 | **후보만 추천하고 사람이 고름(ADR-0007).** 계약 전. 30분 여행 ≈ $0.05 안팎. 동의 문구는 ADR-0007 |
| 클립 보관 | AWS S3 | **사람이 장면으로 확정한 구간의 원음 클립**(ADR-0007). 원음 전체는 차 밖으로 나가지 않음(장면을 고를 때까지 차 안에 암호화, T63) | **씀(T76).** 클립 전용 버킷(`CLIPS_BUCKET`, 서울, 버전 관리 끔 — 버킷·역할은 T64가 만듦). 차량 앱이 API로 올리고 같은 API 주소에서 듣는다(머리말 인증). API가 SDK 기본 자격 체인(서비스 계정 역할)으로 씀. 서명 주소는 쓰지 않음(URL에 자격이 실림). 지우기는 사람의 요청·동의 철회·여행 48시간에 API가 바로 하고, 남은 것은 버킷 수명 규칙(올린 뒤 2일을 다음 UTC 자정으로 올려 만료, 지우기가 비동기라 최대 약 3일)이 치움 |
| 사용자 프로필을 현대 통합계정으로 이어감 | Hyundai Developers 계정 API(OAuth2 인증코드) | 기기 프로필은 기기를 바꾸면 끊김. 현대 계정이면 프로필과 차량(carId)을 이어감 | **구현 유보(ADR-0004).** 콘솔 프로젝트 등록과 제휴 조건 확인 뒤 티켓을 다시 나눔. 차량 데이터는 블루링크 커넥티드카 한정, 공유받은 차량은 제외 |
| 인증서 | Let's Encrypt | HTTPS | 선언은 T5 |

## 원칙

- 외부 API 키는 저장소에 넣지 않습니다. 클러스터에서는 비밀 값으로 주입합니다.
- 사용자 대화나 위치가 외부로 나가는 호출을 넣을 때는 무엇이 어디로 가는지 이 문서와 동의 화면에 같이 적습니다.
- 외부 호출이 실패해도 이미 받은 부탁의 표시와 차량 제어는 계속 돌아야 합니다.
