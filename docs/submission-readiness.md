# 제출 준비 상태와 검증 범위

2026년 11월 14일 release APK를 현재 차량 소스로 갱신했습니다. 같은 날 최신 공식 제출 안내를 확인했으며, 심사용 계정 초대는 필요하지 않습니다. 비공개 저장소의 소스와 APK 압축본을 제출하는 경로를 준비합니다. 이 문서는 제출 완료나 심사 접근 확보를 뜻하지 않습니다.

기존 외부 서명 설정으로 `assembleRelease`를 실행했습니다. 릴리스 lint와 서명 검증을 통과했고, 이전 APK와 인증서가 같습니다. 서명 키와 비밀번호는 저장소에 넣지 않습니다. Java 25.0.4에서는 lint 도구가 실패했고 Java 21로 실행한 같은 빌드는 통과했습니다. [Android의 JDK 설정](https://developer.android.com/build/jdks)은 소스 언어 버전과 빌드 실행 JDK를 구분합니다.

별도 AVD의 사용자 10에서 디버그 앱을 제거하고 release를 새로 설치했습니다. ‘누구랑 같이 타나요?’와 가족 선택 화면, 서버 주소 입력 칸이 없는 것을 확인했습니다. 이 release로 공개 서버에 새 여행을 생성하거나 실제 휴대폰과 연결하지 않았습니다. 같은 소스의 디버그 APK로 수행한 동의·주행·합성 전사·제안·주차·전체 대화 검사는 [T83 결과](../frontend/car/verification/20261114/README.md)에 있습니다.

## 현재 UI의 세로 검토본

[최신 화면 검토 영상](../frontend/car/verification/20261114/current-ui-review.mp4)은 이번 차량 소스의 디버그 APK를 독립 AVD에서 다시 촬영한 것입니다. 841dp 창의 주행·합성 전사·휴게소 제안·‘나중에’ 보관을 담았습니다. 화면을 세로로 자르고 합성 입력 음성과 에뮬레이터 출력을 시각에 맞춰 섞었습니다. ‘Pleos 에뮬레이터 실행 화면 · 합성 음성’ 표기를 전체 구간에 표시합니다.

- 길이 54.96초, 1080×1920, H.264 영상과 AAC 음성입니다.
- SHA-256: `b6668d73764f07ae15556177a7afb9c0c88a3e6d4aa810cf7c10879d5c185bdb`.
- 원본은 `Roaddy/research/evidence/20261114-issue-completion/car-video/current-ui.webm`과 같은 폴더의 합성 WAV입니다. 저장소에 원음·참가자 토큰은 넣지 않습니다.
- 입력 ‘아빠 바다는 언제 보여?’가 이번 녹화에서는 ‘아까 가자는 언제 보여’로 받아 적혔습니다. 대화 3개가 저장되고 전체 보기에도 나오지만, ‘바다’를 찾는 음성 시험의 텍스트 조건은 실패했습니다. 이 녹화를 전사 정확도 시험 통과로 표시하지 않습니다. 자막을 대본으로 덮어쓰지 않았습니다.
- 파일은 검토용으로 저장소와 로컬 전달 폴더에 준비했습니다. 기획 담당에게 메시지를 보내거나 외부에 게시하지 않았습니다.
