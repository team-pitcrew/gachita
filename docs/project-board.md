# 프로젝트 보드(칸반)

SOVA 저장소의 운영 방식을 따릅니다. T번호 이슈가 카드입니다. PR은 `Refs #이슈번호`로 카드에 연결합니다.

## 상태

| 상태 | 언제 | 누가 옮기나 |
|---|---|---|
| Backlog | 시작 전. 선행이 안 끝난 것 포함 | 이슈를 만들 때 |
| Ready | 선행이 끝나 시작할 수 있음 | 담당자 |
| In progress | 브랜치를 만들어 작업을 시작함 | 작업을 시작한 사람 |
| In review | PR을 열고 CI와 리뷰를 기다림 | PR을 연 사람 |
| Done | 완료 기준을 채움. 이슈를 닫음 | PR 병합과 확인 뒤 |

- 보드의 상태는 완료의 증거가 아닙니다. 증거는 PR과 '확인한 것'입니다.
- 끝낸 할 일은 PR이 `develop`에 병합되고 확인한 뒤 이슈에서 체크합니다.
- 일부 PR이 병합됐다고 작업 전체를 닫지 않습니다.
- 다른 사람의 할 일을 대신 체크하지 않습니다.

## 지금 상태 (2026-11-12)

- 이슈와 라벨은 만들었습니다.
- **보드는 아직 없습니다.** `gh` 토큰에 프로젝트 권한이 없어서입니다. 아래 명령은 브라우저 인증이 필요해 계정 주인이 직접 실행합니다.

```sh
gh auth refresh -s project,read:project
.github/scripts/board.sh        # 보드와 상태 열을 만들고 T번호 이슈를 올린다
```

보드가 생기기 전까지는 이슈의 라벨 `status:*`로 같은 다섯 상태를 적습니다. 보드가 생기면 라벨은 지웁니다.

## 로컬 명령

```sh
gh issue list --label "status:in-progress"            # 지금 하고 있는 것
.github/scripts/board.sh status T2 in-progress                # 상태 옮기기(보드가 있으면 보드, 없으면 라벨)
```
