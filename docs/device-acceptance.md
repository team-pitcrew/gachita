## 설치와 오프라인 — T6 #7

1. 휴대폰에서 `https://gachita.mangowhois.ai`를 열고 프로필을 만듭니다. 이름/캐릭터를 고치고 새로고침 후 유지되는지 봅니다. 좌석·공조 선호 자동 적용은 현재 제품 범위가 아닙니다.
2. Android Chrome은 브라우저의 설치 메뉴, iOS Safari는 공유 → 홈 화면 추가로 설치합니다. 홈 화면에서 실행하고 아이콘·이름·화면을 기록합니다.
3. 차의 동승 연결로 여행에 들어가 화면을 읽은 뒤 비행기 모드로 전환합니다. 새로고침하면 마지막 여행과 연결 끊김 안내가 보이고 서버 변경을 성공했다고 표시하지 않아야 합니다.
4. 다시 연결한 뒤 최신 상태를 읽는지 확인합니다. 만료·철회한 대화나 공유는 오프라인 캐시에서 되살아나면 안 됩니다.
5. 실제 Google 계정으로 첫 로그인, 다른 폰의 같은 계정 로그인, 기존 기기 프로필 연결, 취소를 각각 기록합니다. 토큰·인증 코드·계정 개인정보는 캡처에서 제외합니다.

## 모바일 데이터와 공개 주소 — T27 #33

1. Wi-Fi를 끄고 모바일 데이터만 사용해 서비스 홈과 `/healthz`에 접속합니다. `/healthz`는 `{"ok":true}`가 보여야 합니다.
2. 같은 네트워크에서 OAuth를 시작하고 서비스의 `/oauth/google/callback`으로 돌아오는지 봅니다. 인증 취소는 프로필을 만들거나 바꾸지 않아야 합니다.
3. Pleos 에뮬레이터의 제출용 APK가 같은 HTTPS 주소로 여행을 만들고 폰의 동승 연결을 받는지 확인합니다. 개발용 `--es server`가 아닌 기본 주소를 사용합니다.
4. Cloudflare 밖의 ALB 직접 접근 차단과 메일 DNS 보존은 인프라 설정/기존 T27 근거와 별도로 확인합니다. 이 절차를 위해 DNS·메일·보안 그룹을 변경하지 않습니다.

2026-11-14 09:27 KST의 개발 Mac `curl` 조회에서는 `/healthz` 200, `/oauth/google/callback` 200, `/api/config`의 Google Client ID 설정 여부를 확인했습니다. 이는 모바일 데이터 또는 실제 Google 로그인 성공의 증거가 아닙니다. Python 기본 클라이언트는 403을 받았으므로 모든 클라이언트가 통과한다고 기록하지 않습니다.

## 폰의 QR을 차가 읽습니다 — T46 #71

현재 흐름은 **폰이 일회용 동승 QR을 표시하고 주차 중인 차가 읽는 방식**입니다. 옛 ‘차 QR을 폰으로 촬영’ 절차와 구분합니다.

1. 폰에서 프로필 → 동승 연결을 열고 남은 유효 시간을 확인합니다.
2. 주차(P) 상태의 차에서 여행 관리 → 동승자 연결로 카메라를 열고 폰 QR을 보여 줍니다.
3. 차량이 제공하는 빈자리를 고릅니다. 차와 폰에서 같은 참가자/좌석을 표시하고, 기록 동의는 처음에 꺼져 있어야 합니다.
4. 차의 기록 스위치를 켜도 이 폰의 동의는 대기로 남아야 합니다. 폰에서 문구를 읽고 본인이 켠 뒤에만 함께 기록합니다.
5. 같은 QR을 다시 쓰면 거절됩니다. 다른 QR을 읽는 중 기어 D로 바꾸면 카메라가 닫히고 좌석 선택이 막혀야 합니다.
6. 동의를 끄면 기록과 접근이 중지되는지 확인하고, 합성 시험 프로필과 자료를 정리합니다. 실제 가족의 음성을 시험 자료로 요구하지 않습니다.

## 제출 자료와 심사 접근 — T13 #14

- README의 APK 경로·서명·해시와 실행 절차를 최종 릴리스와 맞춥니다. 현재 develop의 개발 APK 시험과 제출 릴리스를 구분합니다.
- 실제 에뮬레이터 녹화에는 ‘에뮬레이터 실행 화면’, 웹 재현에는 ‘웹 시연’, 그린 장면에는 ‘화면 시안’을 표시합니다. 합성 음성을 썼다면 함께 표시합니다.
- 같은 촬영본에서 30~60초 세로본을 준비하고 영상/음성 트랙·길이·해상도·표기를 확인합니다. 외부 게시나 팀원 발송은 별도 지시에 따릅니다.
- 심사 계정 초대는 필요하지 않습니다. 소스·APK 압축본과 최종 커밋을 고정한 뒤 제출할 다운로드 주소를 로그아웃 환경에서 확인합니다. 전체 저장소를 공개로 바꾸는 작업과 구분합니다([제출 규정](submission-package.md)).
