# 여행과 원음 보관 정책

2026-11-14 사용자 요청(T90)으로 여행 생성 후 48시간 자동 만료를 제거합니다. 여행, 전사, 선택 원음, 생성 MP4, 공유는 시간 경과만으로 숨기거나 지우지 않습니다. `expiresAt: null`은 예정된 만료가 없다는 뜻입니다. 기존 48시간 기한도 원본과 세대를 보존한 채 null로 옮깁니다.

동의 철회, 원본 삭제, 공유 회수, 프로필 삭제, 참가자 인증과 세대 검사는 유지합니다. 주차 뒤 차가 올리는 여행 전체 음성(ADR-0024, T132)은 예외로 **다 올린 뒤 2일에 만료**합니다(2026-11-15 01:20 KST 오너 결정 "2일 뒤 만료"). 지우는 것은 클립 버킷의 기존 수명 규칙(올린 뒤 2일)이고, API는 그때부터 `expired`로 보고 장면을 새로 자르지 않습니다. 그 전에도 동의 철회(세대 오름)·여행 삭제·`DELETE /audio`에서 바로 지웁니다. 명시적으로 취소한 생성 작업도 멱등 키는 보존하여 오래된 재전송이 새 유료 작업을 만들지 않게 합니다. 동승 연결 QR의 5분 기한, 인증·요청 제한 시간, 생성 비용 한도는 여행 보관 정책과 별개입니다.

기존 이미지로 되돌리면 시간 삭제가 다시 작동하므로 운영 롤백 시 T90의 보관 정책을 포함한 수정 이미지를 사용합니다. 이미 과거 만료나 철회로 삭제된 파일은 복구하지 않습니다. 유료 생성은 설정이 꺼져 있으면 계속 꺼져 있습니다.

자동 만료에 기대지 않으므로 프로필 삭제는 참가자·토큰·연결 QR을 직접 철회합니다. 삭제와 일반·QR 참가는 프로필별 잠금으로 직렬화하고 여행 철회 후 프로필 삭제를 커밋합니다. 프로필 DB 실패 시 철회한 원음은 복구하지 않으며, 실제 프로필이 살아 있으면 다음 참가 때 삭제 표식을 회수해 계정 사용을 복구합니다.

최초 배포는 기존 48시간 삭제 코드를 가진 파드를 모두 종료한 뒤 새 파드를 시작해야 합니다. 혼합 버전 롤링 배포에서는 구버전이 원음을 삭제할 수 있으므로 Recreate 방식으로 전환합니다.
