# 최종 시안 W1: 함께 타는 중·도착·대화 기록(T127)

2026-11-14 macOS의 Ego Lite(데스크톱 Chromium)에서 CDP로 390×844·모바일 화면을 흉내 내어 찍었습니다. **실제 폰에서 본 것이 아닙니다.** 왼쪽은 Figma(`fJmxFDb3TrpycwDjGJNP62`, 페이지 `2004:57`)의 프레임, 오른쪽은 이 브랜치의 웹앱입니다.

## 어떻게 만들었나

- 이 브랜치의 API를 자기 포트(8841)와 자기 Postgres 컨테이너로 띄웠습니다(공용 `gachita-pg`는 쓰지 않음).
- API로 프로필 하나('아빠', 운전석)와 손님 셋(엄마·서준·하은, 모두 동의), 여행 '강릉 가족 여행', 좌표가 붙은 발화 여덟 줄을 넣고 화자를 붙였습니다. 장소별 할 일은 서버 규칙(`place-rules-v1`)이 그 발화에서 뽑았습니다.
- 도착(P20)은 주차 뒤 `POST /arrival-briefing`(`source: vehicle`)으로 남겼습니다. P21은 마트 할 일 넷을 `PATCH /todos/{id}`로 완료한 뒤 다시 주행으로 바꿨습니다.
- **장소 기록(`places`)은 아직 서버에 없습니다(묶음 A3).** P17 부제의 '하나로마트로 이동 중', P19 곧 도착, P21의 '강릉 숙소로 이동', 대화 기록의 장소 머리는 계획서의 A3 계약 모양(`{name, kind, at, etaSeconds?}`)을 이 로컬 DB의 여행 문서에 직접 넣어 확인했습니다. 장소가 없을 때의 모습은 `P17-drive-no-places.png`입니다(제목만 보임).
- 시각은 찍은 때의 실제 시각이라 시안의 09:20과 다릅니다. 이름·대화는 시안을 따라 만든 합성 값입니다. 토큰과 개인 정보는 남기지 않았습니다.

## 함께 확인한 동작

- P19에서 '확인'을 누르면 P17로 돌아갑니다(이 탭에서만 기억, 새로 고치면 다시 보임).
- 주행 중 '콘텐츠 기록'을 누르면 지금의 쇼츠 화면 규칙대로 '주차한 뒤 쇼츠를 볼 수 있어요.'가 뜹니다.
- 모든 상태에서 가로 넘침이 없었습니다(`scrollWidth ≤ innerWidth`).

## 검토 반영(Astra, 2b1a15a 뒤)

- [P21-todos-503.png](P21-todos-503.png): 마트 할 일을 모두 완료해 '하나로마트의 부탁은 완료'가 보이던 화면에서 브라우저의 `GET /todos`만 503으로 바꾸자, 다음 읽기 뒤 부제가 '하나로마트에서 다시 출발 / 강릉 숙소로 이동'으로 바뀌었습니다(읽기가 실패하는 동안 완료·남은 수를 말하지 않음). 곧 도착·도착 카드는 받아 둔 목록을 보이되 받은 시각을 밝히고 수를 말하지 않습니다(단위 테스트).
- 같은 부탁을 여럿이 말하면 확인된 화자마다 그 사람 카드에 넣습니다(단위 테스트).
- 장소 기록은 배열 순서가 아니라 `at`이 가장 큰 것을 지금 상태로 봅니다(#370 계약, 단위 테스트).

## 시안과 일부러 다른 것

- '가족'은 '일행'·'우리'로 씁니다(P19 부제, P20 부제, P21 제목). 가족 그룹(W5) 전에는 여행에 손님도 탈 수 있어 가족인지 모릅니다.
- 시안 P17–P21은 제목이 탭 위에 겹쳐 그려져 있습니다(시안 결함, 계획서). 앱은 탭 아래에 둡니다.
- 머리의 '9:41'은 폰 상태 막대의 시각이라 그리지 않고 '연결됨'·'연결 끊김'만 둡니다.
- 탭 단추는 손가락 크기(44px)를 지켜 시안(40px)보다 4px 큽니다. 글꼴은 앱의 Pretendard입니다(시안은 Noto Sans KR).
- P19·P20의 부탁 글은 서버가 뽑은 문장 그대로입니다(시안의 '고기와 과일'처럼 줄이지 않음). 장소 카드 안이라 앞의 '○○에서'만 뺍니다. P20 첫 카드의 분홍 바탕은 급한 부탁을 가릴 값이 없어 쓰지 않았습니다.
- 캐릭터는 내 프로필이면 내 것, 다른 사람은 자리 순서의 기본 캐릭터입니다(참가자 문서에 캐릭터가 없음). 그래서 시안과 그림이 다를 수 있습니다.
- '부탁 남기기'는 시안에 없지만 기존 기능이라 주 단추 위에 둡니다(P13의 두 단추 배치). 기록 상태 띠 아래의 '실제 녹음 상태는 차 화면에서 확인해 주세요.'도 남겼습니다.
- 대화 기록의 '추천 장면 고르기'는 지금의 장면 고르기 화면을 엽니다(W2에서 바꿈). 옆에 '자막 수정'을 둡니다.
