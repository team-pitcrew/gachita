- 시안의 '아빠 민준', '엄마의 계정 초대하기', '서준 프로필 만들기', '엄마 참여 확인'의 관계·다음 아이 이름은 서버에 없어 '민준', '가족 계정 초대하기', '아이 프로필 만들기'·'다음 아이 프로필 만들기', '참여 확인'으로 둡니다.

- P11 동의 줄은 시안에 체크 칸이 보이지 않지만 동의를 끌 수 있게 체크 칸을 둡니다(서버도 보호자 동의 없이는 아이를 만들지 않음).
