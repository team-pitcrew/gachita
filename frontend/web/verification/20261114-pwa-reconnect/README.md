# 오프라인 재실행 뒤 프로필 복구

2026-11-14 macOS의 Ego Lite(Chromium)에서 확인했습니다. 실제 iPhone 결과를 대신하는 기록은 아닙니다.

수정 전 공개 서비스에서 프로필이 있는 화면을 연 뒤 네트워크를 끊고 새로고침했습니다. 프로필 토큰은 그대로 있었지만 ‘내 프로필 만들기’가 보였고, 네트워크를 복구해도 그 상태가 유지됐습니다. 새로고침을 다시 해야 기존 프로필이 보였습니다.

수정 후 독립 로컬 서버(49274)와 별도 DB의 합성 프로필 ‘재연결 검증’으로 다음을 확인했습니다.

| 조건 | 결과 |
|---|---|
| 홈을 오프라인으로 다시 열기 | 복구 안내를 표시하고 신규 프로필 만들기를 숨겼습니다. 기존 토큰은 유지됐습니다. |
| 네트워크 복구 | 새로고침 없이 기존 이름과 동승 연결 화면이 돌아왔습니다. 토큰은 바뀌지 않았습니다. |
| 프로필 편집 주소를 오프라인으로 다시 열기 | 빈 생성·편집 양식을 표시하지 않고 복구 안내를 보여 줬습니다. |
| 편집 주소에서 재연결 | 저장된 이름을 채운 기존 프로필 양식으로 돌아왔습니다. |
| 이름을 입력하는 동안 연결 해제·복구 | 저장 전 입력과 포커스를 유지했습니다. |

[검사 결과](checks.json)는 토큰과 개인 정보를 포함하지 않습니다. 프로필·사진·음성의 오프라인 캐시는 추가하지 않았습니다. 같은 토큰의 조회를 합치고, 다른 토큰으로 바뀐 뒤 늦게 도착한 응답은 적용하지 않습니다. 실제 기기 설치·모바일 데이터·OAuth 왕복·QR 연결은 [기기 확인](../../../../docs/device-acceptance.md)에 별도로 기록합니다.
