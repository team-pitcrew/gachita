## 눌러 본 것

- P16C에서 운전석에 엄마를 고름 → P16B에서 민준·엄마가 맞바뀜 → 저장 → P16A '새 좌석을 저장했어요.', 줄이 '운전석 엄마 / 조수석 민준'(PUT 응답 그대로). 확인 뒤 API로 되돌림.
- '+ 새 그룹 만들기'에서 '캠핑 친구들' 저장 → P16G '민준  |  운전석'(만든 사람을 운전석에 앉힘).
- P16A '이 그룹과 출발' → 여행이 만들어지고 앱이 그 여행(#코드)으로 감.
- 자리 없는 사람을 앉은 사람의 자리에 고르면 막는 규칙은 기존 seatPick 그대로라 단위 테스트가 지킴(groups.test.mjs).

## 시안과 다른 점

- 머리 줄: 앱 공통 머리(‹ · 마스코트 · 가치타 · ● 연결됨). 시안의 '9:41 / 연결됨' 자리는 다른 화면과 같게 둠.
- 캐릭터: 앱의 다른 화면(P13 좌석 지도 등)과 같은 캐릭터 그림이라 시안의 '원본 조각'보다 작게 보임.
- 2x2 빈 칸: 시안 차량판은 점선 칸에 '미등록'·'초대 중' 글자가 있으나 폰 28px 칸에는 글자가 들어가지 않아 점선만(초대 중은 민트 점선).
- 반경: 시안의 20 대신 토큰 `--r-phone-card`(24)·`--r-phone-ctl`(16)만 씀(docs/design.md §4).
- 이름: 시연 데이터의 대표가 '민준'이라 P16A·B·C의 '아빠' 자리에 민준이 보임(P16G 시안은 민준).
