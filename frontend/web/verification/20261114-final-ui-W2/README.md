## 시안과 일부러 다른 것

- '가족'은 '우리'·'일행'으로 씁니다(P22 '우리 일행 4명', P31·P32 제목). 가족 그룹(F2) 전에는 여행에 손님도 탈 수 있어 가족인지 모릅니다(W1과 같음).
- P22 부제의 도착 장소('강릉 숙소 도착')는 기록본(`GET /transcript`)의 `places`에서만 읽습니다. 장소를 동의한 참가자에게만 주는 서버 변경(#385)이 아직이라 이 캡처에는 '주차 후 여행 마무리'만 보입니다.
- 파형은 소리의 진폭이 아니라 칸마다 받아 적은 말의 수입니다(폰에는 전체 음성이 없음). 말이 없던 칸은 짧은 점으로 둡니다. P22·P31에서는 진행한 만큼 민트로 칠합니다(시안은 전부 민트).
- 고르기 부제는 실제로 전체 음성을 다 올렸을 때만 '전체 음성에서 찾은', 아니면 '받아 적은 대화에서 찾은 추천 장면 3개'입니다(목업 업로드 중에는 후자).
- 카드 제목은 LLM 없이 장면에서 가장 힘 있는 한 줄(물음표·느낌표, 길이, 확인된 화자)이라 시안의 요약 제목('아빠의 길 안내보다 빠른 서준의 정답')과 다릅니다. 대사 한 줄이 미리 보기 손잡이입니다(시안에 없음). 장면 구간은 서버 규칙(30초 창)이라 2·3번의 끝 시각이 시안과 조금 다릅니다.
- P31의 셋째 줄 '콘텐츠 생성 중'에 실제 진행률(%)과 장면별 상태를 더했고, 안내는 '이 화면을 나가도 완성되면 알려드려요' 대신 실제 동작대로 씁니다: 영상은 폰에서 소리를 재생하며 만들고, 다른 탭으로 가도 계속하지만 폰 화면을 끄거나 앱을 나가면 멈췄다가 돌아오면 이어 만듭니다. '멈추기'를 더했습니다.
- P32 카드 바탕(크림·분홍)은 토큰에 없어 민트 연한 바탕과 surface-2를 번갈아 씁니다. 형식은 기본 영상 하나라 모두 '캐릭터 자막형'입니다(시안의 '가족 대화형' 없음).
- 머리의 '9:41'은 그리지 않습니다(W1과 같음). 글꼴은 앱의 Pretendard입니다.
