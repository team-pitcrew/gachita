# 쇼츠 화면과 기기 보관함

쇼츠는 완성된 영상부터 재생하는 세로 피드입니다. 위아래 넘기기와 이전·다음 버튼을 제공하며, 저장·공유 작업 중에는 선택을 바꾸지 않습니다. 제작 중이거나 실패한 작업은 재생 피드에 섞지 않고 보관함의 제작 현황에 표시합니다.

보관함은 실제 영상에서 추출한 표지, 제목, 길이를 보여 줍니다. 서버의 완성 작업은 `이번 여행`, 직접 보관한 MP4는 `이 기기에 보관`으로 표시합니다. 서버 API는 현재 여행의 목록이며 계정 전체의 개인 영상 목록이 아닙니다. 별도 포스터 API가 없으므로 처음부터 모든 원격 MP4를 받지 않고, 현재 재생하는 파일에서 표지를 만듭니다.

기기 사본은 IndexedDB 트랜잭션이 완료된 뒤 보관 완료로 표시합니다. 프로필은 프로필 ID별로 구분하고 손님은 여행과 독립된 기기 ID를 사용합니다. 홈에서도 보관함을 열 수 있으며, 여행 삭제나 동의 철회로 직접 보관한 파일이 지워지지 않습니다. 기기 보관과 브라우저 파일 다운로드는 별도 동작입니다. 보관함 삭제는 이 앱의 기기 사본만 지우고 따로 내려받은 파일에는 영향을 주지 않습니다. 브라우저 데이터 삭제·저장 공간 정책으로 기기 보관함이 사라질 수 있으므로 영구 서버 앨범으로 표현하지 않습니다.

2026-11-14 사용자의 보관 정책 변경에 따라 여행 생성 후 48시간 제한을 제거했습니다. 웹은 여행 생성 시각으로 대화·자막·장면 후보·원음·쇼츠·공유 접근을 막거나 오프라인 여행 캐시를 지우지 않습니다. 동의 철회, 동의 세대 변경, 참가자·토큰 변경, 원본 삭제, 공유 회수와 주행 중 영상 제한은 유지합니다. 이미 서버나 기기에서 삭제한 자료를 복구하는 변경은 아닙니다.

공유 응답의 `expiresAt: null` 또는 필드 생략은 기한 없음입니다. 전환 중 서버가 유한한 기한을 반환하면 그 공유에만 해당 기한을 적용하며, 새 공유의 기한을 여행 생성 시각에서 계산하지 않습니다. 내려받기 전후의 서버 권한 확인도 유지합니다. QR 동승 연결의 단기 유효기간과 네트워크 요청 제한 시간은 여행 보관 정책과 별개입니다. 서버와 차량의 보관 정책 변경은 각각의 구현에서 검증합니다.

새 제작은 `+ 만들기`에서 시작합니다. 템플릿, 추천 대화, 추가 설정을 확인한 뒤 최종 `동의하고 만들기` 버튼으로 외부 제작에 동의합니다. 보내는 자료는 서버 계획의 `externalData`를 그대로 보여 줍니다. 원음 외부 전달은 추가 설정의 기본 꺼짐 스위치입니다. 제작이 비활성화된 서버에서는 계획 확인과 기본 영상 제작을 제공합니다.

디자인 기준은 사용자가 지정한 [k-style-ui-ux](https://github.com/vmc-inner-circle/k-style-ui-ux) 커밋 `68afa2ea125d0db6b378e5f7ba03b0e4dd010d8e`의 go 스킬, 원칙, 부품, 화면 유형과 비평 체크리스트입니다. 현재 앱의 민트·미색 토큰을 유지하고, 피드는 미디어 배경 위에 영상을 가장 크게 배치합니다. 제작 설정을 피드에서 분리하고, 원형 작업 버튼과 상시 체크박스를 사용하지 않습니다. 별도 정적 시안이 아니라 실제 웹·Android 앱에 적용했습니다.

검증은 모델 단위 테스트, 실제 브라우저의 보관·재진입·삭제·동의 철회, Android MediaStore와 에뮬레이터 재생으로 수행합니다. 공급자 생성과 비용은 별도입니다. 모의 API에 기존 MP4를 연결한 검증은 실제 Higgsfield 생성 품질을 증명하지 않습니다.
