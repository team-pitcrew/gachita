# 가치타 프로필, 초대와 참가

[T19](https://github.com/team-pitcrew/gachita/issues/25) · [T42 문구정리본 반영](https://github.com/team-pitcrew/gachita/issues/60) · 폰 웹앱의 프로필, 그룹 초대와 수락, 여행 참가, 구글 OAuth와 현대 계정을 구분하는 화면 명세

## 목적

가족과 동승자가 로그인 없이도 이름과 얼굴(캐릭터나 사진)을 정해 두고, QR 하나로 그룹이나 여행에 들어와 각자 기록 동의를 고르게 합니다. 첫 고객은 어린 자녀와 이동하는 부모입니다(기준 문서 11/13, [ADR-0009](../../docs/adr/0009-family-group-and-qr-invite.md)).

기본 화면은 **폰 웹앱**(`gachita.mangowhois.ai`)입니다. 이름 입력·프로필 편집·계정 인증은 폰에서 하고, 차에는 참가한 일행과 기록 상태만 보입니다([차량 화면](car.md)). 폰에서는 수음하지 않으므로 목소리 등록은 차에서 합니다([차량 화면](car.md) 흐름 1).

구현 상태는 [차량 화면](car.md)과 같은 말로 적습니다. 웹은 '만듦(웹, 브라우저 확인)'이 데스크톱 브라우저와 ego lite에서 본 것이고, 실제 휴대폰에서 본 것은 아닙니다. 기준은 develop `a7879ad`(11/14)입니다.

## 흐름

### 1. 출발 전: 프로필 만들기와 고치기 — 폰

1. 홈에 프로필이 없으면 '프로필 만들기', 있으면 '{이름} 님'과 '프로필'을 보입니다. 프로필은 참가의 필수 조건이 아닙니다.
2. 프로필에는 **이름 또는 별명**(앞뒤 공백을 뺀 1~20자), **캐릭터**, **사진**(고르면 캐릭터 대신 보임), **기록 동의 기본값**(처음엔 꺼짐)을 넣습니다. 얼굴은 사진, 없으면 캐릭터, 없으면 이름 첫 글자로 보입니다.
3. 캐릭터 목록은 여섯입니다. API 값과 보이는 이름은 `bunny` 토끼, `bear` 곰, `cat` 고양이, `dog` 강아지, `fox` 여우, `penguin` 펭귄입니다. 차와 웹은 같은 값을 씁니다.
4. '저장'을 누르면 중복 제출을 막고, 성공 응답의 프로필 토큰을 이 브라우저에 보관한 뒤 '프로필을 저장했어요'를 보입니다. 토큰을 화면이나 공유 링크에 넣지 않습니다. 실패하면 입력을 그대로 둡니다.
5. 기록 동의 기본값은 다음 참가 화면을 미리 채우는 값일 뿐입니다. 참가할 때 그 여행의 기록 안내를 다시 보이고 사용자가 고릅니다. 기본값만으로 녹음을 시작했다고 표시하지 않습니다.
6. '프로필 지우기'는 확인을 거칩니다. 지우면 앨범의 장면, 내가 대표인 그룹, 내가 만든 아이 프로필까지 지워진다고 먼저 알립니다. 사진만 지우는 '사진 지우기'는 따로 둡니다.

- 이름·캐릭터·사진·동의 기본값·지우기: 만듦(웹, 브라우저 확인, `frontend/web/app.js:196-283`, #135).
- 지금 화면에 남은 '자리 설정'(온도·열선·통풍, `app.js:222-230`)은 11/13 계획에서 뺐습니다. 걷어내는 중(T68 서버, T6 웹).

### 2. 초대: 대표 폰의 그룹 QR과 수락 화면 — 폰

1. **그룹과 대표.** 가족과 동승자는 서버의 그룹으로 묶습니다(가족·동승자 두 종류). 대표 한 사람이 만들고, 계정이 없는 구성원(아이)은 대표가 이름과 캐릭터로 프로필을 만들어 둡니다. 아이는 토큰이 없고, 대표나 차가 여행에 참가시킵니다.
2. **QR 띄우기.** 대표의 폰 웹앱에서 '가족 초대' 또는 '동승자 초대'를 누르면 **그룹 초대 QR**(`https://gachita.mangowhois.ai/j/<초대>`)을 띄웁니다. 초대에는 만료 시각과 횟수 제한이 있고, 화면에 남은 시간과 들어온 사람을 보이며 대표가 취소할 수 있습니다. 차 화면의 QR은 그룹 초대가 아니라 그 여행의 참가 링크입니다(차에 프로필 토큰이 없음, [차량 화면](car.md) 흐름 1).
3. **수락 화면.** 찍은 사람의 폰 브라우저가 설치 없이 '그룹 초대를 받았어요'를 엽니다. 이 폰에 프로필이 있으면 얼굴과 '{이름} 님으로 들어가요'를 보이고 '이 프로필로 들어가기'·'프로필 고치기'를 줍니다. 없으면 '들어가기 전에 이름과 얼굴만 정해요'와 이름·사진·캐릭터 칸, '프로필 만들고 들어가기'를 줍니다.
4. **들어온 뒤.** '{그룹 이름} 그룹에 들어왔어요'를 보입니다. 지금 함께 가는 여행이 있으면 '자리 고르기'로 여행 참가(5절)에 이어지고, 거기서 각자 기록 동의를 고릅니다. 그룹에 들어온 것만으로 기록에 동의한 것으로 보지 않습니다.
5. **쓸 수 없는 초대.** 없거나 취소·만료·횟수를 다 쓴 초대면 '이 초대는 쓸 수 없어요'와 이유, '대표에게 새 초대를 부탁해 주세요'를 보입니다.

- 수락 화면과 쓸 수 없는 초대: 만듦(웹, 브라우저 확인, `app.js:286-328`, #134).
- 서버의 그룹·초대·아이 프로필 API: 만듦(`/api/groups`, `/api/j/{code}`, openapi 0.6.0).
- 대표 폰의 그룹 만들기·QR·남은 시간·취소 화면, 아이 프로필 만들기 화면: 만드는 중(T46 웹).

### 3. 구글 OAuth로 이어 받기·연결하기 — 폰

1. 제공자는 구글 하나입니다(T21, [ADR-0006](../../docs/adr/0006-oauth-provider-google.md)). 구글 설정과 등록된 redirect 주소가 준비된 환경에서만 '구글로 계속'을 보이고, 그렇지 않으면 기기 프로필과 손님 참가를 계속 줍니다.
2. 인증이 끝나면 받은 코드와 그때 쓴 redirect 주소를 서버에 넘깁니다. 클라이언트 비밀 값은 폰에 두지 않습니다.
3. 처음 보는 계정이면 서버가 프로필과 토큰을 만듭니다. 구글에서 받은 이름은 고칠 수 있고, 동의 기본값은 꺼짐으로 시작합니다.
4. 이미 연결된 계정으로 들어오면 같은 프로필을 이어 받고 이 기기의 토큰을 새로 받습니다. 기기마다 토큰을 따로 두므로 다른 기기의 토큰은 계속 씁니다(T68).
5. 이미 기기 프로필이 있으면 '내 프로필 → 구글 계정 연결'로 지금 프로필에 연결합니다. 응답의 `links`가 확인된 뒤 '구글 계정을 연결했어요'를 보입니다.
6. 그 구글 계정이 다른 프로필에 이미 연결돼 `409`가 오면 지금 프로필을 그대로 두고, 두 프로필을 자동으로 합치지 않습니다.
7. 취소하거나 실패하면 원래 화면으로 돌아와 입력을 유지합니다. 같은 코드를 다시 보내지 않습니다.
8. '구글 연결 끊기'는 계정 연결만 없앱니다. 기기 프로필과 토큰은 남습니다.

- 서버: 만듦(`/api/profiles/me/links/google`, T21). 웹 화면: 계획(지금 웹앱에 구글 단추 없음).

### 4. 현대 계정 연결 — 폰, 현재는 안내만

1. 계정 영역에서 구글과 따로 '현대 계정 연결 준비 중'을 보입니다. 누를 수 있는 로그인 단추나 차량 선택 화면은 두지 않습니다.
2. 안내를 열면 '현대 계정 연결은 아직 사용할 수 없어요. 기기 프로필로 계속 이용할 수 있어요'를 보이고 프로필로 돌아갑니다.
3. T22의 제휴·프로젝트 등록 조건이 확인되면 이 절을 고칩니다([ADR-0004](../../docs/adr/0004-hyundai-profile-link.md)). 가족 구성원을 현대 계정에서 받아 오지는 않습니다(ADR-0009).

- 계획(화면 없음).

### 5. 여행 참가 — 폰

1. 차 화면의 참가 QR, 공유받은 링크(`/#<여행 코드>`), 또는 홈의 '초대 코드가 있나요?'로 여행 참가 화면에 들어옵니다. 계정을 만들어야만 참가할 수 있게 하지 않습니다.
2. 프로필이 없으면 이름 → 앉은 자리 → 기록 안내와 동의 순서, 프로필이 있으면 자리 → 기록 안내와 동의 순서로 한 화면에 한 가지씩 묻습니다. 이미 앉은 자리는 고를 수 없습니다.
3. 기록 안내에는 [음성 처리 명세](../../docs/api/voice.md)의 동의 문구를 짧게 보입니다. '동의하고 참가'와 '동의하지 않고 참가'를 둘 다 줍니다. 한 명이라도 동의하지 않으면 기록하지 않는다고 알립니다.
4. 성공하면 참가자 토큰을 이 폰에 보관하고 여행 화면으로 갑니다. 이 참가를 영구 프로필 저장으로 안내하지 않습니다.
5. 여행 화면의 '대화 기록 동의'는 언제든 끌 수 있습니다. 켜기는 이 폰에서 참가한 사람만 그 참가자 토큰으로 합니다. 토큰이 없는 폰에서는 '이 폰에서 참가한 사람만 켤 수 있어요'를 보입니다.

- 참가 단계와 동의 고르기: 만듦(웹, 브라우저 확인, `app.js:375-452`). 지금은 프로필 없이 참가할 때 '온도와 시트' 단계가 있습니다(`app.js:415-429`). 걷어내는 중(T68·T6).
- 동의 켜기의 참가자 토큰: 만드는 중(T68).

## 화면 요소

| 화면 | 중요한 순서와 동작 |
|---|---|
| 홈 | 내 프로필(얼굴과 이름) 또는 '프로필 만들기' → 초대 코드 입력 → '새 여행 만들기' |
| 내 프로필 | 이름 또는 별명 → 사진·캐릭터 → 기록 동의 기본값 → 저장 → 지우기(사진, 프로필) → 계정 연결 |
| 그룹 초대(대표) | 그룹 종류 → QR과 남은 시간 → 들어온 사람 → 초대 취소 → 아이 프로필 만들기 |
| 초대 수락 | 누구의 어떤 그룹인지 → 내 얼굴과 이름 또는 이름·얼굴 칸 → 들어가기 |
| 여행 참가 | 단계 표시(1 / 3) → 질문 하나 → 다음. 마지막은 기록 안내와 두 단추 |
| 여행 화면의 내 칸 | 내 자리 → 대화 기록 동의와 켜기·끄기 |
| 계정 연결 | 구글 연결 상태와 연결·끊기, 현대 계정은 준비 중 항목 |
| 지우기·연결 끊기 확인 | 지우는 것과 남는 것을 짧게 알리고 취소와 확인 |

- 좌석·공조 선호(온도·열선·통풍)는 두지 않습니다(11/13 계획에서 뺌).
- 프로필의 `consentDefault`는 기록 안내를 대신하는 영구 동의가 아닙니다. 수음은 차에서만 하고, 받아 적은 글은 여행을 만든 뒤 48시간 두고 사람이 고른 장면만 남습니다([ADR-0007](../../docs/adr/0007-voice-processing-flow.md)·[ADR-0008](../../docs/adr/0008-in-car-capture-and-sdk-stt.md)).

## 상태

| 상태 | 화면에 보이는 것과 동작 |
|---|---|
| 프로필 없음 / 불러오는 중 | '프로필 만들기'와 손님 참가를 주거나 불러오는 중 표시. 조회 중에 기본값을 서버에 덮어쓰지 않음 |
| 저장 중 / 성공 | 제출을 한 번만 받고 성공 응답 뒤에 완료를 보임. 새 프로필 응답을 잃어도 자동으로 다시 만들지 않음 |
| 입력 오류(`400`) | 이름 1~20자를 그 칸 옆에서 알림. 나머지 입력은 유지 |
| 사진을 읽지 못함 | '이 사진은 읽지 못했어요. 다른 사진을 골라 주세요' |
| 프로필 토큰 오류(`401`) | '프로필을 다시 확인해 주세요'. 계정으로 이어 받거나 새 프로필·손님 참가를 고르게 함 |
| 쓸 수 없는 초대(`404`·`409`) | '이 초대는 쓸 수 없어요'와 이유. 프로필은 지우지 않음 |
| 자리 겹침(`409`) | 이미 앉은 자리를 잠그고 빈자리를 다시 보임. 앞 단계 입력은 유지 |
| 동의 켜기 거절(`401`·`403`) | '이 폰에서 참가한 사람만 켤 수 있어요'. 끄기는 언제나 됨 |
| 구글 인증 취소·거절·충돌 | 원래 화면으로 돌아옴. 충돌(`409`)은 '이미 다른 프로필에 연결된 구글 계정이에요' |
| 통신 끊김 | '연결되면 다시 저장해 주세요'. 입력을 유지하고 저장 완료로 보이지 않음 |
| 주행 중 차량 화면 | 프로필 편집·계정 인증·초대 QR을 열지 않음. 운전자에게 폰 조작을 요구하지 않음 |

### 확인한 근거

- 프로필·초대·참가는 [API 명세](../../docs/api/openapi.yaml)(0.6.0)와 [웹앱](../web/app.js)을 읽어 정리했습니다. 서버 API가 있다는 것과 화면을 만든 것은 구분했습니다.
- 그룹과 QR 초대는 [ADR-0009](../../docs/adr/0009-family-group-and-qr-invite.md), 구글은 [ADR-0006](../../docs/adr/0006-oauth-provider-google.md), 현대 계정은 [ADR-0004](../../docs/adr/0004-hyundai-profile-link.md)를 따릅니다.
- 실제 휴대폰, 실제 구글 로그인, 실차 화면의 QR을 폰으로 읽는 거리와 밝기는 확인하지 않았습니다.
