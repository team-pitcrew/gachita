# 가치타 프로필 만들기와 계정 연결

[T19](https://github.com/team-pitcrew/gachita/issues/25) · 기기 프로필, 구글 OAuth, 현대 계정 연결을 구분하는 화면 명세

## 목적

일행이 로그인 없이도 여행에 참가하고, 원하면 이름·기록 동의 기본값·자리별 선호를 프로필로 저장해 다음 여행에 다시 사용할 수 있게 합니다. 이 자료는 화면 명세와 피그마 인수인계 기준입니다. 앱 구현과 실제 계정 인증·기기 검증은 후속 구현에서 확인합니다.

기본 화면은 **폰 웹앱**입니다. 차량에는 참가한 일행과 확인된 적용 결과만 표시하며, 이름 입력·프로필 편집·계정 인증은 폰에서 진행합니다. 프로필 저장 성공을 차량 설정 적용 성공으로 표시하지 않습니다.

기존 피그마의 [T17 일행 표시](https://www.figma.com/design/Qc58INq2ECd1ODzzmM7Nja?node-id=2-74)와 [기록 동의 대기](https://www.figma.com/design/Qc58INq2ECd1ODzzmM7Nja?node-id=24-248)는 프로필·참가 정보가 차량에 이어지는 참고 화면입니다. 프로필 생성·편집·구글 인증·현대 계정의 상세 흐름은 아래 명세로 전달하며, 기존 T17 프레임을 T19 상세 시안으로 간주하지 않습니다.

## 흐름

### 1. 기기 프로필 만들기와 고치기 — 폰

1. 홈과 여행 참가 첫 화면에 ‘내 프로필’과 ‘프로필 없이 참가’를 제공합니다. 프로필이 없으면 이름·자리별 선호·기록 동의 기본값을 입력하는 화면을 엽니다. 계정 연결은 프로필 생성의 필수 조건이 아닙니다.
2. 이름은 앞뒤 공백을 뺀 1~20자입니다. 선호는 운전석·조수석·뒷자리별로 나누고, 각 자리의 온도·열선·통풍을 편집합니다. 초기값은 22℃·열선 끔·통풍 끔, 기록 동의 기본값은 꺼짐입니다.
3. ‘프로필 만들기’를 누르면 중복 제출을 막고 저장 중 상태를 표시합니다. 생성 성공 응답의 프로필과 토큰을 이 브라우저에 보관한 뒤 ‘프로필을 만들었어요’를 표시합니다. 토큰을 화면이나 공유 링크에 넣지 않습니다.
4. 다음 방문에는 저장한 토큰으로 프로필을 불러옵니다. 사용자가 ‘고치기’에서 이름·선호·동의 기본값을 바꾸고 ‘저장’을 누르면, 성공 응답으로 화면을 갱신합니다. 실패하면 편집값을 유지하며 저장 완료로 표시하지 않습니다.
5. 동의 기본값은 다음 참가 화면을 미리 채우는 값입니다. 참가할 때 해당 여행의 기록 안내를 다시 보여 주고 사용자가 동의 여부를 확인하게 합니다. 참가 요청에는 확인한 `consent` 값을 명시해 보내며, 프로필의 기본값만으로 실제 녹음을 시작했다고 표시하지 않습니다.
6. 프로필을 고쳐도 이미 참가한 여행의 이름·동의·선호가 한꺼번에 바뀌지는 않습니다. 현재 여행의 동의와 선호는 여행 화면의 ‘대화 기록 동의’·‘내 자리 설정’에서 별도로 고칩니다. 프로필로 참가한 사람이 자리를 옮기면 해당 자리 종류의 저장된 선호를 다시 불러옵니다.
7. ‘프로필 지우기’는 별도 확인 화면에서 진행합니다. 성공한 뒤 이 브라우저의 프로필 토큰을 지우고 처음 화면으로 돌아갑니다. 이미 참가한 여행의 이름·선호까지 지워졌다고 알리지 않습니다. 계정을 연결하지 않은 프로필은 토큰을 잃으면 복구할 수 없어 새로 만들어야 합니다.

### 2. 구글 OAuth로 만들기·이어 받기·연결하기 — 폰

1. T21의 결정에 따라 제공자는 구글 하나로 표시합니다. 구글 클라이언트 설정·등록된 redirect 주소·앱의 인증 복귀 처리가 준비된 환경에서만 ‘구글로 계속’을 제공합니다. 준비되지 않은 환경은 기기 프로필과 손님 참가를 계속 제공합니다. 준비 여부를 화면에 전달하는 방식은 앱 구현에서 확정합니다.
2. 프로필이 없는 사람이 ‘구글로 계속’을 선택하면 인증 화면을 엽니다. 인증이 끝나면 받은 코드와 그때 사용한 redirect 주소를 서버에 전달합니다. 클라이언트 비밀 값은 폰 화면이나 브라우저 저장소에 넣지 않습니다.
3. 처음 보는 구글 계정이면 서버가 프로필과 새 토큰을 만듭니다. 구글에서 받은 이름을 확인·수정할 수 있게 하고, 선호는 초기값·동의 기본값은 꺼짐으로 시작합니다. 이름을 받지 못해 ‘이름 없음’으로 온 경우에도 사용자가 이름을 고칠 수 있게 합니다.
4. 이미 연결된 계정이면 같은 프로필을 이어 받습니다. 토큰 없이 계정으로 들어갈 때 새 토큰이 발급되어 **이전 기기의 프로필 토큰은 사용할 수 없게 됩니다**. 인증 전에 이를 알리고, 응답에서 받은 새 토큰으로 이 브라우저의 값을 바꿉니다. ‘여러 기기에서 동시에 이용’으로 안내하지 않습니다.
5. 이미 기기 프로필이 있는 사람은 ‘내 프로필 → 구글 계정 연결’로 들어갑니다. 이때 현재 프로필 토큰을 함께 보내 같은 프로필에 연결합니다. 이름·선호·동의 기본값·현재 토큰은 유지하며, 응답의 `links`가 확인된 뒤 ‘구글 계정을 연결했어요’를 표시합니다.
6. 구글 계정이 다른 프로필에 연결되어 `409`가 오면 현재 프로필을 유지합니다. 두 프로필을 자동으로 합치거나 토큰을 버리고 재전송하지 않습니다. 다른 계정으로 연결을 다시 시작하거나 현재 프로필로 돌아갑니다. 기존 계정의 프로필로 들어가는 선택은 현재 편집을 마친 뒤 별도 로그인 흐름으로 구분합니다.
7. 사용자가 인증을 취소하거나 실패하면 원래 화면으로 돌아와 작성한 내용을 유지합니다. 인증 코드를 그대로 반복 제출하지 않고, 사용자가 다시 선택할 때 새 인증 흐름을 엽니다. 프로필 연결 여부는 서버 조회 결과로 확인합니다.
8. 연결된 프로필에서는 ‘구글 연결 끊기’를 별도로 제공합니다. 확인 후 성공하면 계정 연결 표시만 없앱니다. 기기 프로필과 현재 토큰은 유지됩니다. 이 조작을 구글 계정 삭제나 이미 참가한 여행 삭제로 설명하지 않습니다.

### 3. 현대 계정 연결 — 폰, 현재는 안내만

1. 계정 영역에서 구글과 별도 항목으로 ‘현대 계정 연결 준비 중’을 표시합니다. 활성화된 로그인 버튼이나 차량 선택 화면은 제공하지 않습니다.
2. 안내를 열면 ‘현대 계정 연결은 아직 사용할 수 없어요. 기기 프로필로 계속 이용할 수 있어요’를 표시하고 프로필로 돌아가게 합니다. 구글 인증 경로로 대신 연결하지 않습니다.
3. T22의 제휴·프로젝트 등록 조건이 확인되면 이 절을 갱신합니다. 현대 인증 복귀, 받아올 사용자 정보, 차량 선택 및 carId·VIN 대응은 현재 미정입니다. 차량 소유 정보나 공조 선호를 이미 받아올 수 있다고 표시하지 않습니다.

### 4. 프로필 없이 참가 — 폰

1. 여행 코드를 확인한 뒤 ‘프로필 없이 참가’를 선택합니다. 계정을 만들거나 로그인을 해야만 참가할 수 있는 화면으로 보내지 않습니다.
2. 현재 참가 흐름처럼 이름 → 빈자리 선택 → 이 여행의 온도·열선·통풍 → 기록 안내와 동의 확인 순서로 진행합니다.
3. ‘동의하고 참가’와 ‘동의하지 않고 참가’를 모두 제공합니다. 프로필 토큰을 보내지 않고 이름·자리·동의·선호를 이번 여행의 참가자 정보로 저장합니다.
4. 성공 응답 후 여행 화면으로 이동합니다. 자리 충돌이면 최신 빈자리를 다시 고르게 하며 앞 단계 입력은 유지합니다. 이 참가를 영구 프로필 저장으로 안내하지 않습니다.

## 화면 요소

| 화면 | 중요한 순서와 동작 |
|---|---|
| 참가 시작 | 여행 코드 확인 → 프로필로 참가 또는 프로필 없이 참가 → 필요한 경우 구글로 계속. 프로필 생성은 선택 사항입니다. |
| 내 프로필 | 이름 → 운전석·조수석·뒷자리 선호 → 기록 동의 기본값 → 계정 연결 → 프로필 삭제. 연결된 구글 이메일·사진은 표시하지 않습니다. |
| 선호 편집 | 자리 종류 하나를 선택해 온도·열선·통풍을 편집합니다. API 범위는 온도 16~30℃, 열선·통풍 0~3입니다. 실제 적용은 차량 지원 범위와 조작 허용 조건을 확인한 뒤에만 알립니다. |
| 기록 동의 기본값 | ‘다음 여행에서 사용할 기록 동의 기본값’으로 설명합니다. 이번 여행의 동의를 바꾸는 자리와 분리합니다. |
| 계정 연결 | 구글 연결 상태와 연결·끊기 조작을 표시합니다. 현대 계정은 별도 준비 중 항목으로 둡니다. |
| 삭제·연결 끊기 확인 | 삭제 대상과 남는 정보를 짧게 알리고 취소와 확인을 제공합니다. 프로필 삭제와 구글 연결 끊기를 같은 버튼으로 묶지 않습니다. |

음성 처리는 [ADR-0007](../../docs/adr/0007-voice-processing-flow.md)·[ADR-0008](../../docs/adr/0008-in-car-capture-and-sdk-stt.md)을 따릅니다. 수음은 차량에서만 하고 폰에서는 하지 않으며(11/13), 받아 적은 글은 여행을 만든 뒤 48시간 두고 사람이 고른 장면만 남깁니다. 참가 동의 화면의 안내는 [음성 처리 명세](../../docs/api/voice.md)의 동의 문구와 맞춥니다. 프로필의 `consentDefault`는 그 안내를 대신하는 영구 동의나 클라우드 처리 동의의 별도 증거가 아닙니다.

## 상태

| 상태 | 화면에 보이는 것과 동작 |
|---|---|
| 프로필 없음 / 불러오는 중 | 만들기와 손님 참가를 제공하거나 ‘프로필을 불러오고 있어요’를 표시합니다. 조회 중 기본값을 서버에 덮어쓰지 않습니다. |
| 저장 중 / 성공 | 제출을 한 번만 받고 성공 응답 이후 완료를 표시합니다. 새 프로필 생성 응답을 잃은 경우 자동 재생성을 반복하지 않습니다. |
| 입력 오류 (`400`) | 이름 1~20자, 온도·열선·통풍 범위를 해당 입력 옆에서 알립니다. 나머지 입력은 유지합니다. |
| 프로필 토큰 오류 (`401`) | ‘프로필을 다시 확인해 주세요’를 표시합니다. 계정으로 이어 받거나 새 기기 프로필·손님 참가를 선택하게 합니다. 원인이 확인되지 않았는데 삭제·기기 변경으로 단정하지 않습니다. |
| 구글 인증 취소 / 코드 거절 | 원래 화면으로 돌아갑니다. API의 ‘제공자가 코드를 거절함’(`401`)은 다시 인증하는 안내로 바꾸며 기존 프로필을 삭제하지 않습니다. |
| 구글 계정 충돌 (`409`) | ‘이미 다른 프로필에 연결된 구글 계정이에요’를 표시합니다. 현재 프로필을 유지하고 다른 계정 연결 또는 돌아가기를 제공합니다. |
| 제공자 정보 조회 실패 / 통신 끊김 | ‘지금은 구글 계정을 확인할 수 없어요’를 표시합니다. 사용자 정보 조회 `502`와 통신 실패를 빈 프로필이나 연결 해제로 해석하지 않습니다. |
| 연결 끊기 요청 뒤 연결 없음 (`404`) | 최신 프로필을 다시 읽어 실제 연결 상태를 맞춥니다. 이번 요청의 성공으로 임의 처리하지 않습니다. |
| 기기 프로필 편집 중 통신 끊김 | ‘연결되면 다시 저장해 주세요’를 표시하고 현재 화면의 입력을 유지합니다. 저장 완료나 차량 반영 완료를 표시하지 않습니다. |
| 참가할 자리 없음 / 충돌 (`409`) | 이미 선택된 자리를 잠그고 최신 빈자리를 다시 보여 줍니다. 계정 연결 실패와 구분합니다. |
| 주행 중 차량 화면 | 프로필 편집·계정 인증 화면을 열지 않습니다. 운전자에게 주행 중 폰 조작을 요구하는 안내도 하지 않습니다. |

## 문구

| 자리 | 글자 |
|---|---|
| 진입 | 내 프로필 / 프로필 만들기 / 프로필 없이 참가 |
| 편집 | 이름 / 운전석 선호 / 조수석 선호 / 뒷자리 선호 / 고치기 / 저장 |
| 저장 상태 | 프로필을 저장하고 있어요 / 프로필을 만들었어요 / 프로필을 저장했어요 |
| 동의 기본값 | 다음 여행에서 사용할 기록 동의 기본값이에요. 참가할 때 다시 확인해요. |
| 실제 차량 적용 안내 | 저장한 선호는 차가 지원하는 범위에서 적용해요. |
| 구글 인증 | 구글로 계속 / 구글 계정 연결 / 구글 연결 끊기 |
| 구글 정보 안내 | 구글에서 사용자 번호와 이름을 받아요. 이메일은 받지 않아요. |
| 다른 기기에서 이어 받기 | 이 기기에서 이어 받으면 이전 기기의 프로필 인증은 해제돼요. |
| 구글 연결 결과 | 구글 계정을 연결했어요 / 구글 연결을 끊었어요 |
| 구글 연결 오류 | 이미 다른 프로필에 연결된 구글 계정이에요 / 지금은 구글 계정을 확인할 수 없어요 |
| 현대 계정 | 현대 계정 연결 준비 중 / 현대 계정 연결은 아직 사용할 수 없어요. 기기 프로필로 계속 이용할 수 있어요. |
| 프로필 삭제 | 프로필을 지울까요? 이미 참가한 여행의 이름과 선호는 해당 여행에 남아요. / 취소 / 프로필 지우기 |
| 손님 참가 | 동의하고 참가 / 동의하지 않고 참가 |
| 통신·인증 | 연결되면 다시 저장해 주세요 / 프로필을 다시 확인해 주세요 |

### 확인한 근거와 인수 범위

- 기기 프로필과 손님 참가는 [현재 API 명세](../../docs/api/openapi.yaml), [웹앱 참가 흐름](../web/app.js)을 읽어 정리했습니다. 서버 API가 있다는 사실과 프로필 화면 구현 완료는 구분합니다.
- 구글 흐름은 [T21 PR #53](https://github.com/team-pitcrew/gachita/pull/53)의 [API 명세](https://github.com/team-pitcrew/gachita/blob/1e4ff584e3243cfbadbbb4d7001adcccbc3f8587/docs/api/openapi.yaml), [서버](https://github.com/team-pitcrew/gachita/tree/1e4ff584e3243cfbadbbb4d7001adcccbc3f8587/backend/api), [ADR-0006](https://github.com/team-pitcrew/gachita/blob/1e4ff584e3243cfbadbbb4d7001adcccbc3f8587/docs/adr/0006-oauth-provider-google.md)에 맞췄습니다. 2026-11-13 확인 시 산출물이 작성된 검토 PR이며, 실제 구글 인증·배포 설정의 검증을 뜻하지 않습니다.
- 현대 계정은 [T22 ADR-0004](../../docs/adr/0004-hyundai-profile-link.md)의 구현 유보 결정을 적용했습니다.
- 이 자료는 문서와 코드 계약을 확인한 화면 설계입니다. 프로필 화면의 실제 폰·차량 실행, 실제 구글 로그인과 현대 인증은 여기서 검증하지 않았습니다. 인수 범위는 이 상세 명세와 기존 피그마의 T17 연계 화면입니다.
