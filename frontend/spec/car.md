# 가치타 차량 화면

[T17 차량 화면](https://github.com/team-pitcrew/gachita/issues/23) · 기획서 v4의 주행 중 기록, 정차 제안, 도착 후 확인 흐름

[피그마 기본 흐름](https://www.figma.com/design/Qc58INq2ECd1ODzzmM7Nja?node-id=2-73) · [추가 상태 84개](https://www.figma.com/design/Qc58INq2ECd1ODzzmM7Nja?node-id=22-248)

## 목적

운전자가 주행 중 일행과 기록 상태를 한눈에 확인하고, 안전하게 멈췄을 때 부탁을 처리한 뒤 도착하면 여행 기록을 확인할 수 있게 합니다.

## 흐름

1. **여행 연결과 출발.** 차량 앱이 여행 코드로 일행과 부탁을 불러옵니다. 출발하면 주행 중 화면으로 바꿉니다. 기록에 일행 전원이 동의하고 실제 기록 시작이 확인되면 ‘기록 중’으로 표시합니다. 운전자가 ‘기록 일시정지’를 누르거나 일행 한 명이라도 동의를 철회하면 기록을 멈춥니다. 동의가 다시 모이면 조작이 허용된 상태에서 운전자가 ‘기록 다시 시작’을 선택할 수 있습니다. 창 전환이나 재출발만으로 수동 일시정지가 풀리지 않습니다.
2. **주행 중.** 기록 상태, 일행, 보관한 부탁 수를 표시합니다. 부탁이 추가되어도 개수만 갱신하고, 응답을 요구하는 카드나 음성 질문은 띄우지 않습니다. 차량이 잠깐 멈춰도 Pleos가 조작을 제한하는 동안은 이 화면을 유지합니다.
3. **여행 중 안전하게 정차.** 여행을 계속하는 중이고 차량이 멈췄으며 Pleos가 조작을 허용할 때, 경유지로 제안할 수 있는 부탁을 한 건씩 보여 줍니다. 카드에 짧은 장소명과 ‘경유지로 추가’·‘나중에’를 표시합니다. 제안 시 TTS는 짧은 질문을 한 번만 읽습니다. ‘나중에’를 누르거나 결정 전에 주행 제한이 다시 걸리면 제안을 보관으로 돌리고, 주행 화면으로 돌아갑니다. 이 정차로 여행을 주차 상태로 바꾸거나 기록을 마감하지 않습니다.
4. **제안 수락과 내비 반영.** 운전자가 ‘경유지로 추가’를 누르면 ‘내비에 경유지를 추가하고 있어요’로 바꾸고 중복 입력을 막습니다. 내비가 앞으로 나올 수 있습니다. 내비의 경유지 변경이 확인되면 ‘경유지를 추가했어요’를 표시하고, 실패하면 부탁을 다시 보관합니다. 내비에서 돌아오면 최신 결과를 표시합니다. 이동을 시작하면 제안 카드와 응답 버튼은 닫고, 짧은 결과 문구만 남깁니다. 정차 중에는 Pleos의 오디오 정책이 허용할 때 반영 결과를 한 번만 읽습니다.
5. **도착 후 주차.** 운전자가 기어 P에서 주행 제한이 풀린 상태로 ‘도착했어요’를 선택하면 여행을 주차 상태로 바꾸고 기록을 마감합니다. 기어 P로 잠깐 바꾸는 것만으로는 여행을 마감하지 않습니다. 주차 화면에서 기록 종료와 부탁 처리 결과를 확인합니다. 결과가 준비되면 ‘클립 보기’와 ‘주행 기억 지도 보기’로 이동합니다. 결과가 없거나 아직 준비 중이면 해당 상태를 보여 주고, 편집·지도 탐색·공유는 [T18](https://github.com/team-pitcrew/gachita/issues/24)에서 정합니다.

## 화면 요소

좁은 **Portrait 앱 창 한 칸**을 기본으로 합니다. Driving view는 고정된 시스템 영역입니다. 상태 표시줄과 공조 패널, 앱 목록 등 시스템 UI가 앱보다 위에 표시될 수 있으므로 앱 창 안에서 주요 정보를 확인할 수 있게 합니다. 창이 넓어지거나 앱이 다시 보이면 최신 여행 상태를 확인해 같은 흐름을 이어갑니다. [Pleos 화면 구성](https://document.pleos.ai/docs/connect/guide/docs-design/getting-started/layout) · [창 정책](https://document.pleos.ai/docs/connect/guide/docs-design/getting-started/window)

| 상황 | Portrait의 표시 순서 | Landscape에서 달라지는 점 |
|---|---|---|
| 주행 중 또는 조작 제한 중 | ① 기록 상태 ② 일행 이름 또는 인원 요약 ③ 보관한 부탁 수 ④ 허용되는 경우 기록 일시정지 | 같은 순서를 유지합니다. 여유 공간이 있으면 일행 이름을 펼쳐 보여 줍니다. |
| 조작 가능한 정차 | ① 기록 상태와 일행 요약 ② 제안 카드 한 장 ③ 추가·나중에 버튼 ④ 보관한 부탁 수 ⑤ 기어 P이고 주행 제한이 풀렸을 때 ‘도착했어요’ | 여행 요약 옆에 제안 카드를 배치합니다. 한 번에 한 건만 결정합니다. |
| 도착 후 주차 | ① 기록 결과 ② 부탁 처리 요약 ③ 준비된 클립·지도 진입 버튼 | 여행 요약과 클립·지도 진입 버튼을 나란히 배치합니다. |

- ‘보관한 부탁’은 보관 상태인 건만 셉니다. 제안은 경유지로 사용할 장소가 확인된 부탁만 표시합니다. 장소가 불명확하거나 우회 시간이 확인되지 않으면 추측한 장소·시간을 표시하지 않습니다.
- 주행 제한은 화면이 넓어져도 그대로 적용합니다. 영상·클립 재생, 긴 대화 기록, 부탁 상세 목록, 키보드·검색, 시트·계정 설정, 지도 탐색·편집·공유는 주행 화면에서 숨깁니다. 녹음 파형이나 자동 스크롤도 표시하지 않습니다. 기록 일시정지는 현재 제한에서 허용될 때만 한 번의 조작으로 제공하고, 상태를 알 수 없으면 제한된 화면을 표시합니다. [Pleos 주행 안전 가이드](https://document.pleos.ai/docs/pleos-only/vehicle-app-planning-guide/driver-distraction-guideline)

### 피그마 시안과 창 크기

피그마는 아래 12개 앱 창마다 주행 중·정차·도착 후 3개와 추가 상태 7개를 두어 **총 120개 프레임**으로 구성합니다. 추가 상태는 기록 일시정지, 동의 대기, 내비 반영 대기, 내비 반영 실패, 연결 끊김, 결과 준비 중, 결과 없음입니다. 각 프레임 아래에 상태가 성립하는 조건과 허용되는 조작을 적었습니다. 기본 Portrait는 628 × 855 dp이며 시스템 Driving view·상태 바·GNB는 프레임에 포함하지 않습니다.

| 화면 종류 | Portrait 앱 창 (dp) | Landscape 앱 창 (dp) |
|---|---|---|
| Connect-S 12.9″ | 628 × 855 | 1274 × 855 |
| Connect-S 14.6″ | 672 × 948 | 1360 × 948 |
| Connect-S 17″ | 840 × 1184 | 1700 × 1184 |
| Connect-W | 800 × 810 | 1640 × 810 |
| Connect-W-Extended | 800 × 1400 | 1640 × 1400 |
| Connect-WF | 648 × 800 | 1256 × 800 |

위 값은 설치된 Pleos 시스템 이미지(API 34, x86_64, Pkg.Revision 1)의 `ConnectWebConsole.apk` 안 `assets/web/window-policy.js`에 정의된 `DISPLAY_PRESETS`를 읽어 확인한 설계 기준입니다. dp를 프레임 단위로 사용하며 dpi 변환 뒤의 px와 구분합니다. W 계열의 Portrait·Landscape도 이 프리셋의 좁은 창·넓은 창 이름으로, 화면 회전을 뜻하지 않습니다. 공식 문서의 화면 종류·창 정책과 대조했으며, 이 시안에서 12개 창을 실행하거나 실차에서 측정한 것은 아닙니다.

[에뮬레이터 화면 배치](../../docs/emulator/README.md)에 기록된 **1682 × 1210 px**는 별도 환경에서 실행해 잰 앱 창입니다(160 dpi, 1 dp = 1 px). 이 크기에서는 위 Landscape처럼 여행 요약과 제안·결과를 나란히 배치합니다. **약 841 × 1210**은 그 창을 반으로 나눈 계산값이며 실제 분할 창의 측정값이 아닙니다. 이 경우 Portrait처럼 기록 → 일행 → 부탁 → 허용된 조작 순서로 쌓습니다. 프리셋 크기가 실측값을 대체하지 않으며, 구현은 실제 앱 창 크기와 inset에 맞춰 같은 우선순위를 유지해야 합니다.

피그마의 120개 프레임은 편집 가능한 레이어, 문구, 버튼 노출 조건, 잘림·겹침을 검수했습니다. 이는 명세와 시안의 검수이고, 차량 앱의 에뮬레이터 실행·실차 검증은 아닙니다. 클립·지도 상세 화면은 T18의 범위입니다.

## 상태

| 상태 | 화면에 보이는 것과 동작 |
|---|---|
| 연결된 여행 없음 / 불러오는 중 | ‘연결된 여행이 없어요’ 또는 ‘여행을 불러오고 있어요’를 표시합니다. 여행 코드 입력은 조작이 허용될 때 열 수 있습니다. |
| 보관한 부탁 없음 | 일행과 기록 상태는 유지합니다. ‘보관한 부탁이 없어요’를 표시하고 제안 카드는 열지 않습니다. |
| 기록 중 / 일시정지 / 동의 대기 | 기록 시작이 확인되면 ‘기록 중’, 멈춤이 확인되면 ‘기록을 일시정지했어요’를 표시합니다. 동의가 부족하면 ‘모두 동의하면 다시 기록할 수 있어요’를 표시합니다. 실제 기록 기능을 사용할 수 없으면 ‘지금은 기록할 수 없어요’를 표시합니다. |
| 주행 제한이 다시 시작됨 | 정차·주차 상세 화면과 편집을 닫고 주행 요약을 표시합니다. 수락 전 제안은 보관하고, 수락한 내비 요청은 확인된 결과만 반영합니다. |
| 내비 확인 대기 / 실패 | 수락과 반영 완료를 구분합니다. 확인이 늦으면 대기 문구를 유지하고 다시 누르게 하지 않습니다. 실패와 보관 복귀 저장이 모두 확인된 뒤 ‘부탁은 보관했어요’와 복귀한 건수를 표시합니다. 즉시 재시도 버튼은 두지 않고 다음에 조작이 허용될 때 다시 제안할 수 있습니다. |
| 통신 끊김 / 다시 연결 | 마지막으로 확인한 일행과 부탁 수에 ‘연결이 끊겼어요’·‘마지막으로 확인한 정보예요’를 표시합니다. 끊긴 동안 수락·재개·여행 마감 조작은 제공하지 않으며, 확인되지 않은 동작을 완료로 표시하지 않습니다. 최신 동의를 확인할 수 없으면 기록을 시작하거나 재개하지 않습니다. 기록 중이었다면 동의를 확인할 수 있을 때까지 일시정지하고, 멈춤이 확인된 뒤에만 화면에 알립니다. 연결이 돌아오면 최신 상태를 불러온 뒤 허용 조건을 다시 판단합니다. |
| 주차 후 결과 없음 / 준비 중 / 준비 완료 | 기록 없이 끝났으면 ‘남은 기록이 없어요’를 표시합니다. 처리가 진행 중인 것이 확인되면 ‘여행 기록을 준비하고 있어요’를 표시합니다. 준비가 확인된 결과의 진입 버튼을 엽니다. |

현재 [여행 API](../../docs/api/openapi.yaml)는 기록 여부를 상태로 관리합니다. 실제 녹음과 처리 결과는 T10·T12 확인에 따라 연결하고, 기록 상태 값만으로 녹음 성공이나 클립 생성을 표시하지 않습니다. 내비가 앞에 나오는 동작과 경유지 확인은 [에뮬레이터 관측](../../docs/api/external.md)에 근거하며 실차에서는 확인하지 않았습니다.

기록 표시는 차량 앱의 실제 수음 시작·중단 확인을 따릅니다. 수음은 차량에서만 하고 폰에서는 하지 않습니다([ADR-0008](../../docs/adr/0008-in-car-capture-and-sdk-stt.md), 11/13). 음성 비서(Gleo)와 마이크를 나눠 쓰는 규칙은 ADR-0008과 T41을 따릅니다. [T10 검토 PR #52](https://github.com/team-pitcrew/gachita/pull/52)의 '대표 폰 녹음' 제안은 채택하지 않았습니다.

## 문구

| 자리 | 글자 |
|---|---|
| 여행 연결 | 여행 코드를 입력해요 / 여행을 불러오고 있어요 / 연결된 여행이 없어요 |
| 주행 화면 | 기록 중 / 일행 {인원}명 / 보관한 부탁 {건수}건 |
| 기록 조작 | 기록 일시정지 / 기록 다시 시작 |
| 기록 상태 | 기록을 일시정지했어요 / 모두 동의하면 다시 기록할 수 있어요 / 지금은 기록할 수 없어요 |
| 제안 제목과 음성 | {장소}에 들를까요? |
| 제안 버튼 | 경유지로 추가 / 나중에 |
| 내비 결과와 음성 | 내비에 경유지를 추가하고 있어요 / 경유지를 추가했어요 / 경유지를 추가하지 못했어요. 부탁은 보관했어요 |
| 통신 안내 | 연결이 끊겼어요 / 마지막으로 확인한 정보예요 / 최신 상태를 확인하고 있어요 |
| 도착과 기록 종료 | 도착했어요 / 여행 기록을 마쳤어요 / 남은 기록이 없어요 / 여행 기록을 준비하고 있어요 |
| 주차 후 버튼 | 클립 보기 / 주행 기억 지도 보기 |
