# 차량 참석 QR 방향 수정 검증

차량에 QR을 띄우고 휴대폰 카메라로 읽어 참여하는 T106 변경입니다. 2026-11-14 기준으로 로컬 빌드와 단위 검사를 통과했습니다. 이 기록은 실제 휴대폰 스캔이나 새 APK의 에뮬레이터 화면 성공을 뜻하지 않습니다.

| 검사 | 결과 |
| --- | --- |
| `./gradlew assembleDebug testDebugUnitTest` | 앱·지도 모듈 빌드 성공, 앱 단위 테스트 121개 통과 |
| `make check -o db DATABASE_URL=<격리 DB>` | 웹 69개·API 59개 통과. 공용 개발 DB 대신 이 작업이 만든 Postgres 17 컨테이너를 사용했습니다. |
| `git diff --check` | 통과 |
| 만료·URL·발급 중 닫기 | 같은 서버의 join URL, 정확한 만료 경계, 여행·서버·운전석·주차·화면 변경, 늦은 발급과 중복 폐기를 단위 검사했습니다. |
| 제거한 경로 | 차량 CAMERA 권한과 Camera2 스캔 코드·화면을 제거했습니다. QR 생성에는 기존 ZXing core를 사용합니다. |

산출물은 `frontend/car/app/build/outputs/apk/debug/app-debug.apk`입니다. JDK 21과 Android SDK 34로 만들었습니다. 기존 녹음·글레오·내비 작업 폴더와 에뮬레이터를 변경하지 않았습니다.

API의 T105 변경과 웹의 차량 QR 참여 화면을 먼저 배포해야 합니다. 이후 설치 실행자가 차량 QR → 폰 프로필·좌석 → 차량 참가자 갱신을 확인합니다. 닫기·재발급·주행 시작 뒤 이전 URL이 만료 상태가 되는지도 실제 API에서 확인해야 합니다. 부모 실행자가 수행하는 새 에뮬레이터·휴대폰 검증 결과는 별도 증거로 연결합니다.
