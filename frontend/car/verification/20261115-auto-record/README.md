| [01](01-waiting-parked.png) | 주차 중, 넷 모두 동의(한 사람 철회 뒤 다시 동의) | '기록 준비됨', '본인의 동의를 저장했어요. 모두 동의하면 출발할 때 자동으로 기록해요', 큰 단추 '출발하면 자동으로 기록해요'(눌리지 않음). 서버 여행 `driving`·`recording: false`(철회로 꺼짐), 마이크 없음 |
| [02](02-auto-recording-C17.png) | Virtual Console로 기어 D, 화면은 누르지 않음 | 로그 `자동 녹음 시작 요청`, 서버 여행 `status: driving`·`recording: true`·넷 동의, `dumpsys audio`에 우리 녹음(MIC 16 kHz 2채널). 반쪽 창(창 바로 나눔)에서 C17과 같은 '● 기록 중 · 아래 버튼으로 언제든 멈출 수 있어요'·'기록 중지' |

- 처음 출발: 여행 만들기 → 넷 동의 → 주차 중 '기록 준비됨'(녹음 안 함) → 기어 D → 차가 여행을 주행으로 바꿈 → 서버 기록 표시 켜짐 → 자동 시작(02).
- 철회와 다시 동의: 주차 중 한 사람 철회 → 마이크를 바로 놓음 → 그 사람 다시 동의 → 자동으로 다시 켜지지 않음(01, 서버 기록 표시가 꺼져 있음) → 기어 D → 차가 다시 주행을 알림 → 서버가 모두 동의로 다시 켬 → 자동 시작.
